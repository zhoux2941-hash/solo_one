## 1. 产品概述

围棋死活题练习工具是一款面向围棋爱好者的在线练习应用，提供从初级到高级的50道精选死活题，覆盖角部、边部、中央三大类别。用户通过点击棋盘落子解题，系统实时判断正误并提供参考答案与提示功能，帮助棋手提升死活计算能力。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 访客 | 无需注册 | 浏览并练习所有题目 |

### 2.2 功能模块
1. **练习页面**：棋盘交互区、题目信息区、操作按钮区、统计信息区
2. **题目列表页面**：分类筛选、题目导航、进度展示

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 练习页面 | 棋盘交互区 | Canvas绘制9路/13路/19路棋盘，支持点击落子、落子放大动画效果 |
| 练习页面 | 题目信息区 | 显示题目编号、难度等级、分类标签、题目描述 |
| 练习页面 | 操作按钮区 | 提交答案、提示、查看参考答案、重置、下一题 |
| 练习页面 | 统计信息区 | 显示解题用时、尝试次数、正确/错误反馈 |
| 题目列表页面 | 分类筛选 | 按角部死活/边部死活/中央死活分类筛选 |
| 题目列表页面 | 题目导航 | 网格展示所有题目，显示完成状态 |
| 题目列表页面 | 进度展示 | 显示总完成数、正确率统计 |

## 3. 核心流程

用户进入应用后，可在题目列表页浏览并选择题目，也可直接进入当前题目练习。练习流程如下：

```mermaid

    "加载棋盘与初始局面" --> "用户落子"

    "判断落子是否合法" -->|"合法"| "显示落子动画"

    "系统判断正误" -->|"错误"| "显示失败提示"

    "下一题" --> "加载棋盘与初始局面"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：木纹暖色系（#D4A76A 棋盘色、#1A1A2E 深色背景）
- 辅助色：墨黑（#0D0D0D 棋子黑）、瓷白（#F5F5F0 棋子白）
- 强调色：朱红（#C0392B 正解标记）、翠绿（#27AE60 提示标记）
- 按钮风格：圆角矩形，带微妙阴影，hover时轻微上浮
- 字体：Noto Serif SC（标题）+ Noto Sans SC（正文），营造棋道文化感
- 布局：左右分栏，左侧棋盘为主，右侧信息与操作面板
- 图标风格：极简线条图标，配合围棋元素

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 练习页面 | 棋盘交互区 | Canvas木纹棋盘，黑白棋子带渐变光泽，落子时缩放动画(1.2x→1.0x)，最后落子标记红点 |
| 练习页面 | 题目信息区 | 题号标签、难度星级、分类徽章、题目文字说明 |
| 练习页面 | 操作按钮区 | 主按钮(提交答案)朱红填充，次按钮(提示/重置)描边样式，答案按钮淡灰底 |
| 练习页面 | 统计信息区 | 计时器数字、尝试次数徽章、正误结果弹出动画 |
| 题目列表页面 | 分类筛选 | 顶部三个Tab按钮（角部/边部/中央），选中态下划线 |
| 题目列表页面 | 题目导航 | 5列网格，每格显示题号+难度星标+完成状态勾 |
| 题目列表页面 | 进度展示 | 顶部进度条+文字"已完成 X/50" |

### 4.3 响应式设计
- 桌面优先设计，大屏左右分栏布局
- 平板端：棋盘与信息面板上下排列
- 移动端：棋盘全宽，操作面板底部固定，触控优化

### 4.4 3D场景指引
- 不适用，本项目为2D Canvas应用
