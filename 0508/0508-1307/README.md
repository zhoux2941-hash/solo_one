# 古代星表可视化工具

## 项目简介

这是一个基于Three.js的古代星表可视化工具，包含托勒密星表（约100颗恒星）的3D天球展示。

## 功能特性

- **3D天球展示**：使用Three.js绘制3D天球，显示恒星位置
- **岁差校正**：支持选择不同观测年份（公元137年至3000年），系统根据岁差模型重新计算恒星坐标
- **星名搜索**：支持搜索星名（中文、拉丁名、拜耳命名）并高亮显示
- **星座连线**：显示主要星座的连线
- **投影模式**：支持球面投影（3D天球）和墨卡托投影（2D平面）
- **CSV导出**：导出当前年份的星表为CSV文件

## 技术栈

- 后端：Node.js + Express
- 前端：Three.js + 原生JavaScript
- 数据存储：JSON格式（预置托勒密星表数据）

## 安装与运行

```bash
# 安装依赖
npm install

# 启动服务
npm start
```

服务启动后，访问 http://localhost:8080 即可使用。

## API接口

- `GET /api/stars?year=2024` - 获取恒星数据（支持岁差校正）
- `GET /api/constellations` - 获取星座数据
- `GET /api/stars/search?q=织女星&year=2024` - 搜索恒星
- `GET /api/stars/csv?year=2024` - 导出星表为CSV
- `GET /api/health` - 健康检查

## 使用说明

1. **观测年份选择**：在控制面板中选择不同年份，观察岁差对恒星位置的影响
2. **投影模式切换**：可在3D球面和2D墨卡托投影之间切换
3. **搜索恒星**：在搜索框中输入星名（支持中文、拉丁名、拜耳命名）
4. **点击恒星**：点击任意恒星查看详细信息
5. **控制选项**：可切换星座连线和星名标签的显示
6. **导出数据**：点击"导出星表CSV"按钮下载当前年份的星表数据

## 数据说明

本项目使用托勒密《天文学大成》中的恒星数据，历元为公元137年。包含约100颗主要亮星，涵盖：
- 中文星名（基于中国古代星官系统）
- 拉丁名（西方传统星名）
- 拜耳命名法
- 所属星座
- 赤经、赤纬（J2000历元）
- 视星等
