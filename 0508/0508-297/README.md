# WebGPU 高精度布料模拟系统

基于WebGPU实现的实时布料物理模拟系统，采用质点-弹簧模型、连续碰撞检测(CCD)算法和动态撕裂效果。

## 核心特性

### 物理系统
- **质点-弹簧模型**: 包含结构弹簧、剪切弹簧和弯曲弹簧
- **Verlet积分**: 稳定的位置积分，无显式速度存储
- **连续碰撞检测(CCD)**: 
  - TOI (Time of Impact) 算法检测高速运动碰撞
  - 保守推进防止穿透
  - 支持球体和立方体碰撞体
  - 可调节CCD迭代次数
- **自碰撞**: 防止布料自身穿透

### 渲染系统
- **PBR材质**: Cook-Torrance BRDF，支持金属度和粗糙度调节
- **法线贴图**: 程序化法线纹理增加细节
- **动态阴影**: 基于法线的简单阴影效果
- **碰撞体可视化**: SDF线框渲染

### 风力系统
- 定向风场
- 湍流/涡流效果（基于正弦噪声）
- 可调节风速和强度

### 相机控制
- **轨道模式**: 左键旋转，右键平移，滚轮缩放
- **第一人称模式**: WASD移动，鼠标转向，Shift加速

## 运行方式

### 环境要求
- 支持WebGPU的浏览器（Chrome 113+, Edge 113+）
- 本地HTTP服务器

### 启动服务器
```bash
# 使用Python
python -m http.server 8080

# 或使用Node.js
npx http-server -p 8080
```

然后在浏览器中访问: `http://localhost:8080`

## 参数说明

### 网格设置
- **分辨率**: 布料网格的细分程度（最高200x200）

### 物理参数
- **结构刚度**: 控制相邻质点间距保持（0-1）
- **剪切刚度**: 控制对角变形抵抗（0-1）  
- **弯曲刚度**: 控制布料褶皱弹性（0-1）
- **阻尼系数**: 能量损耗系数（0.9-0.999）
- **重力**: 向下加速度（-20到0）

### 风力设置
- **风力大小**: 风场强度（0-50）
- **湍流强度**: 涡流噪声幅度（0-10）
- **风速**: 噪声动画速度（0-5）
- **启用风力**: 开关风场影响

### 碰撞设置
- **启用形状碰撞**: 开关球体/立方体碰撞
- **启用自碰撞**: 开关布料自身碰撞
- **碰撞距离**: 碰撞检测阈值（0.005-0.1）
- **碰撞刚度**: 碰撞响应强度（0-1）
- **CCD迭代**: 连续碰撞检测迭代次数（1-10）
- **碰撞形状**: 选择球体或立方体

### 渲染设置
- **金属度**: PBR金属属性（0-1）
- **粗糙度**: PBR粗糙属性（0-1）
- **启用阴影**: 开关动态阴影
- **启用法线贴图**: 开关细节纹理

## 技术细节

### 连续碰撞检测(CCD)
传统离散碰撞检测在高速运动时会出现" tunneling "（穿透）问题。本系统实现了TOI算法：

1. 计算质点从prevPosition到position的运动线段
2. 求解线段与碰撞体的最早碰撞时间t
3. 若t在[0,1]范围内，在碰撞点处停止并沿法线方向推出
4. 用剩余时间继续处理滑动

### 动态撕裂效果实现
布料撕裂基于质点间弹簧连接的张力检测：

1. **8方向连接**: 每个质点与8个相邻质点连接（4个正交+4个对角线）
2. **张力阈值**: 当质点间距离超过原长的`撕裂阈值`倍时，连接断裂
3. **位掩码存储**: 使用u32的低8位存储撕裂状态，每一位代表一个方向是否已断裂
4. **约束跳过**: 约束求解时检查位掩码，跳过已断裂的连接
5. **阻尼冲量**: 断裂时沿法线方向施加阻尼，吸收能量防止过度震荡
6. **可视化**: 撕裂边缘显示红色，断裂连接越多颜色越亮

### 约束求解
- 每帧执行5次子迭代
- 每次迭代依次执行: 积分 -> CCD -> 约束求解 -> 自碰撞 -> 法线更新
- 使用雅可比方法求解弹簧约束

### WebGPU计算管线
- 顶点计算: 64线程工作组
- 约束求解: 128线程工作组
- 碰撞检测: 64线程工作组
- 法线计算: 64线程工作组

## 性能建议
- 分辨率高于100x100时可能在低端GPU上出现性能问题
- CCD迭代次数建议3-5次，次数越高越稳定但开销越大
- 自碰撞对性能影响较大，必要时可关闭
