# 局域网P2P文件分发工具

基于 WebRTC DataChannel 的局域网 P2P 文件传输工具，无需中心服务器中转数据。

## 功能特性

- ✅ 显示本机 IP 和设备名称
- ✅ 自动扫描局域网内在线节点
- ✅ 节点列表显示设备名称、IP、在线状态
- ✅ 支持选择多个目标节点发送文件
- ✅ 单个文件最大支持 500MB
- ✅ 实时显示传输进度、速度、预计剩余时间
- ✅ 接收方弹出通知，可选择保存路径
- ✅ 支持断点续传
- ✅ 历史传输记录，可重试失败任务
- ✅ WebRTC DataChannel 直连传输
- ✅ SQLite 数据持久化存储

## 技术栈

- **前端**: Electron + 原生 JavaScript
- **信令服务器**: Node.js + Socket.io
- **P2P 传输**: WebRTC DataChannel
- **数据存储**: SQLite (sql.js)

## 安装与运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动应用

```bash
npm start
```

这将同时启动：
- 信令服务器 (端口 3000)
- Electron 客户端

## 使用说明

### 发送文件

1. 确保多台设备在同一局域网内
2. 在每台设备上启动应用
3. 在左侧"在线节点"列表中选择目标节点（支持多选）
4. 点击"发送文件"按钮，选择要发送的文件
5. 等待对方接受，传输自动开始

### 接收文件

1. 当有文件发送请求时，会弹出接收对话框
2. 点击"接受并保存"，选择保存位置
3. 如果文件已存在部分，会自动断点续传

### 查看传输记录

- 右侧面板显示所有传输记录
- 可切换查看"全部"、"发送"、"接收"记录
- 失败的任务可以点击"重试"按钮重新发送

## 项目结构

```
p2p-file-share/
├── src/
│   ├── main/           # Electron 主进程
│   │   └── main.js     # 主进程入口，数据库、文件操作
│   ├── renderer/       # 渲染进程
│   │   ├── index.html  # 主界面
│   │   ├── style.css   # 样式文件
│   │   └── app.js      # 核心逻辑：WebRTC、文件传输
│   └── server/         # 信令服务器
│       └── index.js    # Socket.io 信令服务
├── package.json
└── README.md
```

## 注意事项

1. 确保防火墙允许应用访问网络
2. 两台设备必须在同一局域网内
3. 信令服务器默认运行在 localhost:3000
4. 大文件传输建议使用有线网络以获得更好稳定性
