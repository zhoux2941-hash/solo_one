## 1. 产品概述
Huffman编码可视化工具，帮助用户理解Huffman编码算法的原理与过程。用户输入文本后，系统自动统计字符频率、构建Huffman树、生成变长编码，并以可视化二叉树和逐步演示的方式呈现算法执行过程，同时展示压缩效果对比。
- 目标用户：计算机科学学生、算法学习者、对数据压缩感兴趣的开发者
- 核心价值：将抽象的Huffman编码算法转化为直观的可视化交互体验

## 2. 核心功能

### 2.1 用户角色
无需角色区分，所有用户均可使用全部功能。

### 2.2 功能模块
1. **主页面**：文本输入、频率统计、Huffman树可视化、编码表、压缩对比、逐步演示、导出JSON

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 文本输入区 | 用户输入文本（支持英文大小写字母和空格），实时校验输入合法性 |
| 主页面 | 频率统计面板 | 统计每个字符的出现频率，以柱状图或表格形式展示 |
| 主页面 | Huffman树可视化 | 以二叉树形式展示Huffman树，每个节点显示字符和频率，叶子节点高亮，连线标注0/1 |
| 主页面 | 编码表 | 展示每个字符对应的Huffman变长编码 |
| 主页面 | 压缩对比 | 显示原始8位编码总比特数 vs Huffman编码总比特数，计算压缩率 |
| 主页面 | 逐步演示 | 用户可逐步查看Huffman树的构建过程，每次合并两个最小频率节点，支持前进/后退/重置 |
| 主页面 | 导出JSON | 将编码表导出为JSON文件下载 |

## 3. 核心流程

用户输入文本 → 系统统计字符频率 → 构建Huffman树 → 生成编码表 → 展示压缩对比 → 支持逐步回放和导出

```mermaid
flowchart TD
    "A[用户输入文本]" --> "B[统计字符频率]"
    "B" --> "C[构建Huffman树]"
    "C" --> "D[生成Huffman编码]"
    "D" --> "E[展示编码表]"
    "D" --> "F[压缩比特数对比]"
    "C" --> "G[逐步演示树构建过程]"
    "E" --> "H[导出编码表JSON]"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深墨绿(#0D1B2A) + 琥珀金(#F0A500)点缀，营造算法严谨与智慧感
- 辅助色：冷灰(#1B2838)背景 + 翠绿(#00C9A7)节点 + 暖白(#E0E0E0)文字
- 按钮风格：圆角微凸3D按钮，悬停时发光效果
- 字体：JetBrains Mono（代码/编码展示）+ Noto Sans SC（UI文字）
- 布局风格：单页应用，左右分栏，左侧输入+统计+编码表，右侧树可视化+逐步演示
- 节点风格：圆形节点，叶子节点翠绿底色带字符，内部节点深色底色带频率，连线标注0/1

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 文本输入区 | 深色背景输入框，底部实时字符计数，输入校验提示 |
| 主页面 | 频率统计面板 | 横向柱状图，琥珀金填充，字符标签+频率数值 |
| 主页面 | Huffman树可视化 | Canvas/SVG绘制二叉树，节点圆形带发光，连线标注0/1，叶子节点高亮 |
| 主页面 | 编码表 | 表格形式，字符|频率|编码|码长，等宽字体显示编码 |
| 主页面 | 压缩对比 | 双进度条对比，原始比特数/压缩比特数/压缩率百分比 |
| 主页面 | 逐步演示 | 底部控制栏：上一步/下一步/重置/自动播放，当前步骤描述文字 |
| 主页面 | 导出JSON | 按钮，点击下载JSON文件 |

### 4.3 响应式设计
- 桌面端优先，左右分栏布局
- 平板端：上下堆叠布局
- 移动端：单列布局，树可视化支持缩放拖拽
