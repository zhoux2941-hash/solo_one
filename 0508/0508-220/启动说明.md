## 启动步骤

### 第一步：启动后端服务

**方式一：使用脚本启动（推荐）**
```
双击运行 start-backend.bat
```

**方式二：使用 IDE 启动**
1. 用 IntelliJ IDEA 打开 `backend` 目录
2. 等待 Maven 依赖自动下载完成
3. 找到 `ProductionManagementApplication.java` 并运行

**验证后端是否启动成功：**
- 浏览器访问：http://localhost:8080/api/h2-console
- 能看到H2数据库控制台说明启动成功

---

### 第二步：启动前端

**方式一：直接打开文件（最简单）**
```
直接用浏览器打开：frontend/login.html
```

**方式二：使用本地服务器**
```bash
cd frontend

# 如果安装了 Node.js
npm install -g http-server
http-server -p 8081

# 然后访问 http://127.0.0.1:8081
```

## 常见问题

### Q: 后端启动失败怎么办？
**A:** 
1. 确保已安装 JDK 8 或以上版本
2. 确保已安装 Maven 3.6 或以上版本
3. 使用 IntelliJ IDEA 打开项目启动更稳定

### Q: 前端提示"网络错误"？
**A:** 
1. 检查后端服务是否已启动
2. 访问 http://localhost:8080/api/h2-console 确认后端正常
3. 刷新浏览器重试

### Q: 登录后没反应？
**A:** 
1. 按 F12 打开浏览器控制台查看错误
2. 确认后端服务正在运行
3. 检查是否有跨域错误
