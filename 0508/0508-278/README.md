# PBD 软体机器人仿真系统 (肌肉驱动版)

基于Position Based Dynamics (PBD)的软体机器人仿真系统，支持主动肌肉驱动实现蠕虫式爬行。

## 🦾 核心功能：肌肉驱动系统

### 肌肉纤维模型
- 每条肌肉纤维连接两个粒子
- 可配置最大收缩率（默认25%）
- 可配置肌肉强度
- 正弦波形控制激活程度

### 肌肉分组控制
- 软体沿Z轴方向分为5个肌肉组
- 每个肌肉组有独立的激活相位
- 支持行波式收缩，模拟蠕虫运动

### 四种运动模式
1. **Wave (波浪模式)** - 行波式收缩，基础爬行模式
2. **Peristaltic (蠕动模式)** - 类似蚯蚓的蠕动
3. **Undulation (波动模式)** - 更快的波动频率
4. **Standing (静止模式)** - 肌肉完全放松

### 实时参数调节
- **频率调节** (,/.键): 控制收缩速度 (0.1-5.0 Hz)
- **振幅调节** (/'键): 控制收缩强度 (0.0-2.0)
- **肌肉开关** (M键): 一键启用/禁用肌肉系统

## 性能优化

### 1. 弯曲约束构建优化
- **原实现**: O(n²) 双重循环检测所有面对
- **新实现**: O(n) 使用边-面哈希表映射，直接查找相邻面

### 2. 约束求解优化
- 固定粒子的约束早期跳过
- 约束内存预分配避免重新分配
- 简化拉伸和体积约束的求解公式

### 3. 应力计算优化
- 应力计算间隔可调（默认每2帧计算一次）
- 间隔计算对可视化质量影响很小

## 功能特性

### 核心仿真功能
- **四面体网格表示**：使用四面体网格离散化软体对象
- **PBD约束求解**：
  - 拉伸约束（Stretch Constraint）
  - 体积保持约束（Volume Constraint）
  - 弯曲约束（Bending Constraint）- 可开关
  - **肌肉约束** - 主动驱动，周期性收缩
- **高斯-赛德尔迭代求解**：多次迭代求解约束
- **阻尼**：速度阻尼增强数值稳定性

### 碰撞检测与响应
- 平面碰撞器（Plane Collider）
- 球体碰撞器（Sphere Collider）
- 盒体碰撞器（Box Collider）
- 支持碰撞恢复系数和摩擦

### 刚体-软体耦合
- 刚体动力学模拟
- 软体粒子与刚体碰撞响应
- 软体可以抓取和推动刚体

### 可视化
- OpenGL实时渲染
- 应力分布可视化（颜色映射：蓝->绿->黄->红）
- **肌肉激活可视化**（颜色映射：粉红->亮红表示激活程度）
- 线框/实体渲染模式切换
- 粒子/边缘/肌肉显示控制
- 可交互相机（旋转、缩放）
- FPS计数器和统计信息显示

### 文件导入
- 支持OBJ格式网格导入

## 📊 可调参数

### 物理参数
- **弹性系数（杨氏模量）**：控制材料的刚度
- **阻尼系数**：控制能量耗散
- **迭代次数**：约束求解精度与性能权衡
- **弯曲约束开关**：性能/质量权衡

### 肌肉参数
- **全局频率**：肌肉收缩的周期速度 (0.1-5.0 Hz)
- **全局振幅**：肌肉收缩的最大强度 (0.0-2.0)
- **最大收缩率**：每条肌肉可缩短的最大比例 (25%)
- **肌肉强度**：肌肉收缩的力系数

### 其他
- **应力计算间隔**：可视化性能优化
- **重力**：仿真环境的重力加速度

## 性能调优建议

### 对于>5000顶点的大型网格
1. **关闭弯曲约束** (按B键): 减少约30-50%的求解时间
2. **降低迭代次数** (按1键): 迭代8-10次通常足够
3. **增大应力计算间隔** (按0键): 每5-10帧计算一次即可
4. **关闭边缘渲染** (按E键): 减少绘制调用

### 预期性能参考
在现代CPU上：
- 8x8x8网格 (512粒子): >40 FPS
- 10x10x10网格 (1000粒子): ~25-30 FPS
- 关闭弯曲约束后: 性能提升~40%

## 技术细节

### PBD算法流程
1. **位置预测**：根据速度和外力预测下一帧位置
2. **肌肉约束投影**：应用肌肉收缩约束
3. **碰撞检测**：检测并处理碰撞
4. **约束投影**：多次迭代求解所有约束（拉伸、体积、弯曲）
5. **刚体耦合**：处理软体与刚体的相互作用
6. **速度更新**：根据位置变化更新速度
7. **应力计算**：间隔计算四面体应力用于可视化

### 肌肉驱动原理
1. 软体沿Z轴分为多个肌肉组
2. 每个肌肉组根据全局相位计算激活度：
   ```
   activation = 0.5 + 0.5 * sin(2π * frequency * time + phase)
   ```
3. 激活度乘以振幅得到最终收缩程度
4. 肌肉纤维约束修改目标长度实现主动收缩
5. 不同肌肉组有相位差，形成行波

### 约束类型
- **拉伸约束**：保持四面体边缘长度，防止过度拉伸
- **体积约束**：保持材料体积守恒（不可压缩特性）
- **弯曲约束**：控制材料的弯曲刚度（可选）
- **肌肉约束**：主动收缩驱动，实现运动
