# 局域网设备探测桌面客户端

基于Java Swing开发的局域网设备探测工具，支持网段扫描、设备信息采集、端口探测和结果导出。

## 功能特性

### 1. 网段自定义设置模块
- 支持多种网段格式输入
  - IP范围格式：`192.168.1.1-255`
  - CIDR格式：`192.168.1.0/24`
- 预设常用网段快速选择
  - 192.168.1.1-255
  - 192.168.0.1-255
  - 10.0.0.1-255
  - 172.16.0.1-255

### 2. 在线设备扫描模块
- 多线程并发扫描（默认50线程）
- 实时扫描进度显示
- 可随时停止扫描
- ICMP Ping检测设备在线状态

### 3. 设备信息采集模块
- 自动采集设备IP地址
- 自动获取设备MAC地址（通过ARP协议）
- 自动解析设备主机名
- 记录设备响应时间

### 4. 端口简易探测模块
- 探测常用服务端口：
  - 21 (FTP)
  - 22 (SSH)
  - 23 (Telnet)
  - 25 (SMTP)
  - 53 (DNS)
  - 80 (HTTP)
  - 110 (POP3)
  - 135, 139, 445 (Windows共享)
  - 143 (IMAP)
  - 443 (HTTPS)
  - 3306 (MySQL)
  - 3389 (RDP)
  - 8080, 8443 (HTTP代理)

### 5. 扫描结果导出模块
- 支持TXT文本格式导出
- 支持CSV表格格式导出
- 自动生成带时间戳的文件名

## 架构设计

### 核心模块解耦设计

```
com.networkscanner
├── Main.java              # 程序入口
├── model/
│   └── DeviceInfo.java    # 设备信息实体类
├── scanner/
│   ├── NetworkScanner.java # 核心网络扫描逻辑
│   └── ScanListener.java   # 扫描回调接口
├── exporter/
│   └── ResultExporter.java # 结果导出模块
└── ui/
    └── MainFrame.java      # Swing主界面
```

### 关键特性
- **界面与逻辑完全解耦**：通过`ScanListener`接口实现事件通知
- **面向接口编程**：易于扩展新的扫描功能
- **多线程架构**：扫描任务在后台线程执行，不阻塞UI
- **线程安全**：使用`volatile`和线程安全集合保证并发安全

## 环境要求

- JDK 11 或更高版本
- Maven 3.6 或更高版本
- Windows / Linux / macOS

## 快速开始

### 编译项目
```bash
mvn compile
```

### 运行程序
```bash
mvn exec:java -Dexec.mainClass="com.networkscanner.Main"
```

### 打包JAR
```bash
mvn package
java -jar target/lan-device-scanner-1.0.0.jar
```

## 使用说明

1. **选择/输入网段**
   - 从下拉框选择预设网段，或手动输入
   - 支持格式示例：
     - `192.168.1.1-255`
     - `192.168.1.0/24`

2. **开始扫描**
   - 点击"开始扫描"按钮
   - 观察进度条和状态栏
   - 发现的设备会实时显示在表格中

3. **停止扫描**
   - 点击"停止扫描"可随时中断扫描

4. **导出结果**
   - 扫描完成后点击"导出结果"
   - 选择保存位置和文件格式（TXT/CSV）
   - 导出文件包含完整的设备信息

## 技术栈

- **UI框架**：Java Swing
- **构建工具**：Apache Maven
- **网络编程**：Java NIO / InetAddress
- **并发编程**：ExecutorService, Future, SwingWorker

## 注意事项

1. MAC地址获取需要管理员权限
2. 防火墙可能影响扫描结果准确性
3. 扫描大量IP地址时建议适当调低线程数
4. Windows系统ARP缓存可能影响MAC地址获取
