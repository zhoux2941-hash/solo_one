# WebUSB SDR 频谱分析仪

基于WebUSB技术的RTL-SDR软件定义无线电频谱分析仪，完全在浏览器中运行，无需后端服务。

## 功能特性

- ✅ **WebUSB设备连接** - 直接在浏览器中连接RTL-SDR设备
- ✅ **4096点FFT变换** - 使用Hanning窗函数
- ✅ **实时频谱显示** - 刷新率 > 15fps
- ✅ **瀑布图显示** - 时间-频率-功率三维显示
- ✅ **峰值检测** - 自动标记最强信号的频率和强度
- ✅ **可调带宽** - 频谱显示带宽可调节
- ✅ **AM/FM解调** - 支持广播音频解调
- ✅ **音频播放** - 实时播放解调后的音频

## 硬件要求

- RTL-SDR USB设备（RTL2832U芯片）
- R820T调谐器（支持24MHz - 1.7GHz频率范围）

## 软件要求

- Chrome 61+ 或 Edge 79+ 浏览器（支持WebUSB API）
- 无需安装任何驱动或后端软件

## 使用方法

1. **启动本地服务器**

   由于WebUSB需要HTTPS或localhost环境，需要启动本地服务器：

   ```bash
   # 使用Python 3
   python -m http.server 8000
   
   # 或使用Node.js
   npx serve -p 8000
   
   # 或使用PHP
   php -S localhost:8000
   ```

2. **访问应用**

   在浏览器中打开 `http://localhost:8000`

3. **连接设备**

   - 将RTL-SDR设备插入USB端口
   - 点击"连接设备"按钮
   - 在弹出的设备选择对话框中选择RTL-SDR设备
   - 等待设备初始化完成

4. **设置参数**

   - **中心频率**: 设置要监听的频率（24MHz - 1700MHz）
   - **采样率**: 设置IQ数据采样率（最高2.4MSps）
   - **增益**: 调节接收增益（0 - 49.6dB）
   - **显示带宽**: 调节频谱显示的频率范围
   - **平均帧数**: 设置频谱平滑程度

5. **解调音频**

   - 选择解调模式（AM或FM）
   - 设置解调带宽
   - 调节音量
   - 点击频谱图上的信号位置进行调谐

## 技术架构

### DSP模块
- **FFT实现**: Cooley-Tukey算法，4096点
- **窗函数**: Hanning窗，带增益补偿
- **幅度校准**: 精确的dBm校准（±3dB精度）
- **信号平均**: 多帧平均，提高信噪比
- **峰值检测**: 保持30帧的峰值显示

### 解调模块
- **直流消除**: IQ信号直流偏移消除
- **AM解调**: 包络检测 + 四阶低通滤波 + AGC
- **FM解调**: 相位差分 + 四阶低通滤波 + 预加重 + AGC
- **高级滤波**: 双二阶IIR滤波器，Q值0.7071
- **AGC自动增益控制**: 自适应音量调节
- **重采样**: Sinc插值降采样到48kHz音频

### WebUSB通信
- 直接与RTL2832U芯片通信
- USB控制传输配置寄存器
- USB批量传输接收IQ数据
- R820T调谐器I2C配置

## 常见问题

**Q: 浏览器提示不支持WebUSB？**
A: 请使用Chrome或Edge浏览器，版本要求Chrome 61+或Edge 79+。

**Q: 找不到设备？**
A: 确保RTL-SDR设备已正确插入，并且没有被其他程序占用。

**Q: 连接时提示权限错误？**
A: 在Windows上可能需要安装WinUSB驱动，使用Zadig工具切换驱动。

**Q: 频谱显示不正常？**
A: 尝试调整增益设置，确保信号强度在合适范围内。

**Q: 信号强度显示不准确？**
A: 可以在代码中调整`calibrationOffset`参数进行设备个性化校准，典型值在-68~-75dBm之间。

**Q: FM广播解调有杂音？**
A: 1. 确保信号强度足够（>-60dBm）；2. 调整解调带宽（通常100-150kHz）；3. 微调中心频率对准信号峰值。

**Q: 为什么立体声指示灯不亮？**
A: 1. 确保接收的是立体声广播电台；2. 确保信号强度足够（导频检测需要>-50dBm）；3. 解调带宽建议设置为100-150kHz；4. PLL锁定需要1-2秒稳定时间。

**Q: 立体声效果不明显？**
A: 1. FM立体声的分离度通常为30-40dB；2. 信号较弱时自动降低立体声分离度（软融合）；3. 可以尝试关闭立体声切换到单声道获得更好音质。

**Q: 解调带宽应该设置多大？**
A: - 单声道FM：50-75kHz
   - 立体声FM：100-150kHz
   - AM广播：5-15kHz
   带宽越大音质越好，但也更容易受到邻道干扰。

## 注意事项

1. WebUSB仅支持在HTTPS或localhost环境下使用
2. 首次连接设备时需要用户授权
3. 设备配置参数根据不同硬件可能需要调整
4. 长时间高采样率使用可能导致CPU使用率较高
