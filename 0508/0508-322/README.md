# 基于WebRTC的无人机FPV图传与控制系统

一个低延迟的无人机第一人称视角（FPV）图传和控制系统，使用WebRTC技术实现视频流传输和实时控制。

## ✨ 功能特性

### 📹 视频传输
- **低延迟**: 使用WebRTC实现端到端视频传输，延迟<200ms
- **实时显示**: 浏览器端实时显示无人机摄像头画面
- **自适应分辨率**: 支持640x480及更高分辨率

### 🎮 控制系统
- **虚拟摇杆**: 
  - 左摇杆：油门（上下）/ 偏航（左右）
  - 右摇杆：俯仰（上下）/ 横滚（左右）
- **低延迟控制**: DataChannel传输控制指令，响应延迟<100ms
- **键盘控制**: 支持WASD和方向键控制
- **50Hz控制频率**: 每20ms发送一次控制指令

### 📊 飞行数据显示
- 高度（米）
- 速度（米/秒）
- 电池电压（伏特）
- 卫星数量
- 延迟实时显示

### 🚀 一键操作
- 🚀 起飞
- 🪂 降落
- 🏠 返回起飞点

## 🚀 快速开始

### 方法一：浏览器测试（无需树莓派）

**连接流程：先启动发射端，再启动控制端**

1. **窗口A - 发射端（先操作这个）**
   - 打开 `transmitter-browser.html`
   - 点击"启动摄像头"
   - 点击"创建Offer"
   - **复制**生成的SDP Offer文本

2. **窗口B - 控制端（后操作这个）**
   - 打开 `index.html`
   - 点击"连接无人机"
   - **粘贴**刚才从发射端复制的SDP Offer
   - 点击确定后，**复制**生成的SDP Answer文本

3. **回到窗口A - 发射端**
   - 在Answer文本框中**粘贴**控制端生成的Answer
   - 点击"设置Answer"

4. **完成！**
   - 现在可以看到视频流并使用摇杆控制了

### ✅ 已修复问题

1. **控制延迟大** - DataChannel改为`ordered: false`（无序传输），大幅降低控制指令延迟
2. **返航不降落** - 点击返航按钮后，无人机将在3秒内自动降落到地面，高度显示会逐步降至0
3. **电压不更新** - 电池电压现在独立更新，即使没有控制指令也会持续下降（模拟真实耗电）

### 方法二：树莓派发射端

#### 硬件要求
- 树莓派3/4/5
- USB摄像头或树莓派相机模块
- 无人机飞控（如Pixhawk/ArduPilot）

#### 安装依赖

```bash
cd transmitter
pip install -r requirements.txt
```

#### 运行发射端

```bash
python drone_transmitter.py
```

#### 连接步骤

1. 运行Python发射端脚本
2. 复制生成的SDP Offer
3. 在浏览器控制端粘贴Offer
4. 复制控制端生成的Answer
5. 在Python终端粘贴Answer

## 🎯 使用说明

### 摇杆控制

| 摇杆 | 方向 | 功能 | 范围 |
|------|------|------|------|
| 左摇杆 | 上/下 | 油门（增加/减少高度） | -100 ~ +100 |
| 左摇杆 | 左/右 | 偏航（左转/右转） | -100 ~ +100 |
| 右摇杆 | 上/下 | 俯仰（前进/后退） | -100 ~ +100 |
| 右摇杆 | 左/右 | 横滚（左倾/右倾） | -100 ~ +100 |

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| W/S | 增加/减少油门 |
| A/D | 左转/右转偏航 |
| ↑/↓ | 俯仰前进/后退 |
| ←/→ | 横滚左倾/右倾 |
| 空格 | 所有控制归零 |

### 一键操作按钮

- **🚀 起飞**: 自动起飞到安全高度（约1.5米）
- **🪂 降落**: 缓慢降落到地面
- **🏠 返航**: 返回起飞点位置

## 🔧 技术实现

### WebRTC配置

```javascript
iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' }
]
```

### 控制协议

#### 控制指令（50Hz发送）
```json
{
    "type": "control",
    "timestamp": 1234567890,
    "throttle": 50,
    "yaw": -20,
    "pitch": 30,
    "roll": 0
}
```

#### 遥测数据（10Hz发送）
```json
{
    "type": "telemetry",
    "altitude": 1.5,
    "speed": 2.3,
    "battery": 12.4,
    "satellites": 8,
    "timestamp": 1234567890
}
```

#### 动作指令
```json
{
    "type": "action",
    "action": "takeoff",
    "timestamp": 1234567890
}
```

## 🔐 安全注意事项

1. **始终在视线范围内飞行**
2. **遵守当地无人机法规**
3. **保持电池电压在安全范围内**
4. **测试时先进行低空悬停测试**
5. **确保有足够的卫星信号（>6颗）**
