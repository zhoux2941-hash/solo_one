# 去中心化 MUD 游戏引擎

基于 WebRTC + CRDT + DHT 的 P2P 多人地牢探险游戏

## 技术架构

### 核心技术栈
- **WebRTC DataChannel**: P2P 节点间直接通信
- **CRDT (Conflict-free Replicated Data Type): 无冲突的游戏状态同步
- **DHT (Distributed Hash Table): 分布式节点发现和房间信息查询
- **React + TailwindCSS**: 现代化的文本终端风格前端

### 核心特性
- 完全去中心化，无需中心服务器
- 每个节点既是客户端也是中继节点
- 基于文本的回合制战斗系统
- 房间探索和物品系统
- 最多支持 8 人同时在线
- **AI动态剧情生成**: 基于GPT-2风格的增强文本生成系统
- **隐藏线索系统**: 每个房间都有隐藏线索等待发现
- **独特剧情种子**: 每次游戏都有不同的剧情走向
- **玩家行为追踪**: AI根据你的行为调整剧情
- **随机事件系统**: 探索时有机会触发特殊事件
- **怪物和物品风味文本**: 每个怪物和物品都有独特描述

## 游戏玩法

### 1. 开始游戏
1. 输入你的角色名称
2. 点击"开始游戏"

### 2. P2P 连接
要与其他玩家连接：

**方式一: 作为邀请方**
1. 点击"创建邀请"
2. 将生成的邀请码发送给对方
3. 等待对方接受后，将对方的应答码粘贴到"粘贴对方的应答码"
4. 点击"确认连接"

**方式二: 作为被邀请方**
1. 粘贴对方的邀请码到"粘贴对方的邀请码"
2. 点击"接受邀请"
3. 将生成的应答码发送给对方

### 3. 游戏命令

| 命令 | 缩写 | 说明 |
|------|------|------|
| `north` | `n` | 向北移动 |
| `south` | `s` | 向南移动 |
| `east` | `e` | 向东移动 |
| `west` | `w` | 向西移动 |
| `look` | `l` | 观察当前房间 |
| `inventory` | `i` | 查看背包和属性 |
| `pickup <物品ID>` | `get/take` | 拾取物品 |
| `attack <怪物ID>` | `kill/fight` | 攻击怪物 |
| `say <内容>` | `chat` | 发送聊天消息 |
| `players` | `who` | 查看在线玩家 |
| `help` | `?` | 显示帮助信息 |

## 核心功能详解

### WebRTC P2P 网络
- 使用 RTCPeerConnection 建立点对点连接
- RTCDataChannel 进行实时数据传输
- 自动消息中继，支持多节点网络
- 节点状态自动检测和重连

### CRDT 状态同步
- 基于向量时钟的操作排序
- 自动合并冲突，保证最终一致性
- 新节点自动同步历史操作
- 支持 Set/Add/Remove/Delete 四种操作类型
- **改进**: 修复了 `getOperationsSince` 逻辑，确保操作不会丢失
- **新增**: 完整状态快照机制，支持快速状态恢复
- **新增**: 操作排序算法，保证按正确顺序应用

### 重连与状态恢复
- **完整同步机制**: 节点重连时自动触发全量状态同步
- **重试机制**: 带超时和重试的可靠同步
- **状态验证**: 自动验证玩家、房间、怪物状态的一致性
- **HP恢复**: 断线重连时如果玩家已死亡，自动在入口复活
- **房间同步**: 确保玩家在房间列表中的状态正确
- **多节点同步**: 同步完成后自动与所有节点进行增量同步

### DHT 分布式哈希表
- 分布式键值存储
- 房间节点信息查询
- 数据自动复制到多个节点
- 支持数据的插入、查询和删除

### 游戏引擎
- 5 个预设房间组成的地牢地图
- 4 种不同怪物（哥布林、幼龙、骷髅战士、幽灵）
- 6 种不同物品（武器、防具、药水、饰品）
- 回合制战斗系统
- 死亡后自动在入口重生
- 房间人数限制（最多 8 人）

## AI剧情系统详解

### GPT-2风格文本生成
- **增强模板系统**: 基于高质量奇幻文本库的模板引擎
- **种子随机化**: 使用随机种子确保每次体验都独一无二
- **上下文感知**: 根据玩家进度动态调整描述
- **风格定制**: 支持黑暗奇幻、神秘、史诗等多种叙事风格

### 隐藏线索系统
- 每个房间都包含1个线索（普通/中等/重要三个等级）
- 线索发现基于探索次数和剧情进度
- 发现的线索会影响后续事件和描述
- 线索会指向特定的房间或揭示地牢秘密

### 剧情进度追踪
- **探索进度**: 已访问房间数 / 总房间数
- **战斗进度**: 已击败怪物数 / 总怪物数
- **线索收集**: 已发现线索数 / 总线索数
- **物品收集**: 背包中的物品数量
- **综合评分**: 基于所有因素的总体进度百分比

### 随机事件系统
- 每次移动有30%概率触发随机事件
- 事件类型包括：幽灵出现、神秘低语、远古回音等
- 事件描述会根据当前上下文动态调整

## 注意事项

1. WebRTC 需要 STUN 服务器进行 NAT 穿透
2. 首次连接需要手动交换信令（邀请码/应答码）
3. 游戏状态通过 CRDT 自动同步到所有连接节点
4. 房间信息通过 DHT 分布式存储
5. AI剧情生成在本地运行，无需额外服务器
6. 使用不同种子可以获得完全不同的游戏体验
