## 1. 产品概述

传统剪纸"三折法"互动模拟应用，让用户在虚拟环境中体验中国传统剪纸艺术。通过三次对称折叠和镂空绘制，最终生成精美的对称剪纸图案。

- 主要用途：教育娱乐、文化传承、创意设计工具
- 目标用户：剪纸爱好者、学生、设计师、对传统文化感兴趣的大众
- 产品价值：降低剪纸学习门槛，随时随地体验剪纸乐趣，直观展示对称美学原理

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册，直接使用 | 完整的折叠、绘制、展开、预览功能 |

### 2.2 功能模块

1. **主操作页面**：纸张显示区、折叠控制区、绘制工具区、预览区
2. **折叠系统**：三次折叠动画（左右对折→上下对折→角对角折）
3. **绘制系统**：鼠标/触摸绘制裁剪线条，支持粗细调整
4. **对称展开系统**：基于折叠层数的对称图案自动生成
5. **预览系统**：实时预览当前折叠状态和最终展开效果

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主操作页面 | 纸张显示区 | 正方形纸张展示，折叠状态实时更新，绘制区域交互 |
| 主操作页面 | 折叠控制区 | 三个折叠按钮（左右对折、上下对折、角对角折），重置按钮 |
| 主操作页面 | 绘制工具区 | 画笔粗细调整，清除绘制，颜色选择 |
| 主操作页面 | 展开控制区 | 展开按钮，最终效果展示 |
| 主操作页面 | 预览区 | 小窗口实时显示展开后的对称效果预览 |

## 3. 核心流程

用户打开应用 → 显示正方形纸张 → 依次点击三次折叠按钮（每次折叠后纸张形状变化）→ 折叠完成后在纸上绘制裁剪线条 → 实时预览对称效果 → 点击"展开"按钮 → 展示完整对称剪纸图案 → 可保存或重新开始

## 4. 用户界面设计

### 4.1 设计风格

**设计理念：中国传统美学与现代交互设计的融合**

- **主色调**：中国红 (#C41E3A) 作为主色，米白色 (#F5F0E6) 作为纸张底色，深棕色 (#3D2914) 作为辅助色
- **配色方案**：
  - 纸张：米白色 (#F5F0E6)，带有轻微的纸张纹理
  - 折叠线：金色 (#D4AF37) 虚线，体现传统韵味
  - 裁剪线：黑色 (#1A1A1A) 实线，带有毛笔笔触效果
  - 按钮：中国红渐变，悬停时有金光效果
- **按钮风格**：圆角矩形，微微凸起的3D效果，点击时有按压动画，边框采用传统回纹装饰元素
- **字体**：
  - 标题：「华文行楷」或「Ma Shan Zheng」手写风格字体，体现书法艺术
  - 正文：「Noto Serif SC」或宋体，保持传统阅读体验
  - 字号：标题 28px，正文 16px，按钮文字 18px
- **布局风格**：
  - 居中对称布局，体现剪纸的对称美学
  - 主操作区在中央，控制面板分布在左右两侧
  - 采用传统卷轴式边框装饰
  - 背景使用淡雅的云纹图案作为底纹
- **图标/装饰元素**：
  - 使用剪纸风格的图标（折叠、画笔、展开等）
  - 角落装饰传统剪纸花纹（如意纹、云纹）
  - 加载动画使用旋转的剪纸图案

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 主操作页面 | 纸张显示区 | 居中的大尺寸画布（600×600px），米白色纸张背景，金色折叠线，阴影效果模拟纸张厚度 |
| 主操作页面 | 折叠控制区 | 左侧垂直排列三个折叠按钮，带有步骤指示器（1→2→3），已完成步骤显示金色对勾 |
| 主操作页面 | 绘制工具区 | 右侧控制面板，包含画笔粗细滑块、颜色选择器、清除按钮、橡皮擦工具 |
| 主操作页面 | 展开控制区 | 底部中央的大尺寸"展开"按钮，完成所有折叠后才启用，带有脉冲动画提示 |
| 主操作页面 | 预览区 | 右上角小尺寸预览窗口（200×200px），实时显示对称效果，带有"预览"标签 |

### 4.3 响应性

- 桌面优先设计，支持 1280px 及以上分辨率
- 平板适配：调整控件大小和间距，保持操作便捷性
- 移动端：重新布局为垂直排列，折叠按钮改为水平排列，纸张区域自适应屏幕宽度
- 触摸优化：增大按钮点击区域（最小 44×44px），支持触摸绘制
- 画布自适应：使用 SVG 或 Canvas 的响应式缩放，保持图案比例不变

### 4.4 动效设计

- **折叠动画**：每次折叠使用 CSS 3D transform 模拟真实纸张折叠效果，带有自然的缓动曲线（ease-in-out，600ms），折叠过程中显示折痕渐变
- **绘制反馈**：鼠标悬停在画布上时显示自定义毛笔光标，绘制时有轻微的墨迹扩散效果
- **展开动画**：逐步展开的动画效果，从三角形→正方形→矩形→完整正方形，每一步都展示对称图案的生成过程（每层展开 400ms）
- **按钮交互**：悬停时按钮上浮 2px 并发光，点击时下沉 1px，已完成的折叠按钮变灰并显示对勾
- **过渡效果**：所有状态切换使用平滑过渡（300ms ease-in-out）
