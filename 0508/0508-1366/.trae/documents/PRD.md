## 1. 产品概述
中继器网络拓扑模拟器是一个交互式网络可视化工具，允许用户通过拖拽方式创建和配置中继网络拓扑，模拟信号在多跳网络中的传播路径和衰减情况。
- 主要用途：网络规划、教学演示、中继网络设计验证
- 目标用户：网络工程师、学生、科研人员

## 2. 核心功能

### 2.1 功能模块
1. **主画布**：节点拖拽添加、节点连接、网络可视化
2. **控制面板**：节点属性编辑、模拟控制、自动布局
3. **信息面板**：路径结果展示、信号衰减数据、节点详情

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主页面 | 画布区域 | 支持拖拽添加路由器节点，节点间连线形成网络 |
| 主页面 | 属性面板 | 编辑节点最大跳数限制、信号范围等属性 |
| 主页面 | 控制栏 | 模拟按钮、自动布局按钮、清空画布按钮 |
| 主页面 | 信息展示区 | 显示源到目标的路径、信号衰减值、覆盖范围 |

## 3. 核心流程
用户从工具栏拖拽路由器节点到画布，点击节点连接按钮创建节点间链路，设置源节点和目标节点，配置各节点的最大跳数限制，点击模拟按钮后系统计算有效路径并可视化展示信号覆盖范围和衰减值。

```mermaid
flowchart LR
    A["开始"] --> B["拖拽添加节点"]
    B --> C["连接节点形成网络"]
    C --> D["配置节点属性"]
    D --> E["选择源/目标节点"]
    E --> F["点击模拟按钮"]
    F --> G["计算路径和信号衰减"]
    G --> H["可视化展示结果"]
    H --> I["可调整参数重新模拟"]
```

## 4. 用户界面设计
### 4.1 设计风格
- 主色调：深蓝色(#1e3a5f)作为主色，科技感青色(#00d4ff)作为强调色，深灰背景营造专业网络工具氛围
- 按钮风格：圆角矩形，渐变边框，hover时有发光效果
- 字体：JetBrains Mono（代码/数字），Noto Sans SC（中文）
- 布局：左侧工具栏 + 中央画布 + 右侧属性面板的三栏布局
- 图标：线条风格，科技感网络图标

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI Elements |
|-----------|-------------|-------------|
| 主页面 | 画布区域 | 深色网格背景，节点带发光效果，连接线动画，覆盖范围半透明圆形 |
| 主页面 | 工具栏 | 垂直排列工具按钮，节点拖拽源，状态指示灯 |
| 主页面 | 属性面板 | 卡片式布局，滑块控件，数值输入，颜色编码的状态指示 |

### 4.3 响应性
- 桌面端优先，支持1200px以上最佳体验
- 画布区域自适应窗口大小
- 面板可折叠以适应较小屏幕

### 4.4 交互效果
- 节点拖拽：平滑跟随，碰撞检测
- 连线：贝塞尔曲线，信号流动动画
- 覆盖范围：呼吸效果，渐变透明度
- 路径高亮：脉冲动画指示数据流向
