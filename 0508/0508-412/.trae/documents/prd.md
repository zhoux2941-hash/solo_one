## 1. 产品概述

GeoHash 编码解码器是一款基于 Web 的地理位置哈希工具，帮助开发者和地理信息从业者快速进行经纬度与 GeoHash 编码之间的双向转换，并通过可视化网格直观理解 GeoHash 的空间划分原理。

- 解决经纬度与 GeoHash 字符串之间快速、批量互转的需求
- 面向 GIS 开发者、后端工程师、空间数据分析师等技术用户

## 2. 核心功能

### 2.1 功能模块

1. **编码器页面**：单个/批量经纬度转 GeoHash，精度可调（1-12字符）
2. **解码器页面**：GeoHash 反向解码为经纬度范围，Canvas 网格可视化矩形区域，展示相邻8个区域

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 编码面板 | 输入经纬度（单个或批量），选择精度，生成 GeoHash 字符串 |
| 主页面 | 解码面板 | 输入 GeoHash，解码为经纬度中心点和范围 |
| 主页面 | 网格可视化 | Canvas 绘制 GeoHash 矩形区域及相邻8个区域 |
| 主页面 | 预设点位 | 提供天安门、自由女神像等常见地标一键填充 |

## 3. 核心流程

### 3.1 编码流程
用户输入经纬度 → 选择精度(1-12) → 点击编码 → 显示 GeoHash 字符串及对应区域信息

### 3.2 解码流程
用户输入 GeoHash → 点击解码 → 显示经纬度范围 → Canvas 绘制网格 → 标注相邻8个区域

### 3.3 批量流程
用户输入多行经纬度 → 选择精度 → 点击批量编码 → 列表展示所有结果

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深青色(#0D9488) + 暗色背景(#0F172A)，营造科技感地理工具氛围
- 辅助色：琥珀色(#F59E0B)作为高亮/交互强调色
- 按钮风格：圆角8px，hover时微微上浮+阴影
- 字体：JetBrains Mono（数据/编码区域）+ Noto Sans SC（界面文字）
- 布局风格：左右双栏布局，左侧编码/解码操作区，右侧可视化展示区
- 图标风格：lucide-react 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 编码面板 | 输入框(经度/纬度)、精度滑块(1-12)、编码按钮、结果展示卡片 |
| 主页面 | 解码面板 | 输入框(GeoHash)、解码按钮、结果展示(中心点+范围) |
| 主页面 | 网格可视化 | Canvas画布、网格线、中心区域高亮、8个相邻区域标签 |
| 主页面 | 预设点位 | 下拉选择器/标签列表、点击即填充 |
| 主页面 | 批量转换 | 多行文本输入区、批量编码按钮、结果表格 |

### 4.3 响应式
- 桌面优先设计，大屏双栏布局
- 中等屏幕上下排列
- 移动端单栏堆叠，Canvas 自适应缩放
