# 脑电图波形模拟与分析系统

## 功能特性

### 1. 脑电波形模拟
- 正常脑电模式
- 癫痫发作间期模式（含棘波）
- 癫痫发作期模式（含棘慢复合波）
- 8导联 EEG 数据 (Fp1, Fp2, C3, C4, P3, P4, O1, O2)
- 采样率: 256 Hz
- 时长: 10 秒

### 2. Canvas 波形显示
- 静态波形绘制
- 8导联切换显示
- 网格背景和时间轴
- 点击波形可手动标记可疑位置

### 3. 棘波/尖波检测
- 多级验证机制，降低假阳性率
- 带通滤波预处理 (1-70Hz)
- 候选峰值检测 (>2.5倍标准差)
- 基于模板匹配的自动检测 (默认阈值0.85)
- 波形形态学验证 (峰值位置、幅值显著性、上升沿斜率、持续时间约束)
- 局部显著性验证 (>2倍局部标准差)
- 非极大值抑制 (100ms内取最优)
- 预置癫痫棘波、尖波、棘慢复合波模板
- 可调节匹配阈值 (0.70-0.98)
- 检测结果显示波形类型、幅值、持续时间等详细信息
- 检测结果可视化标记

### 4. 频率功率谱分析
- 快速傅里叶变换 (FFT)
- 显示 δ (0.5-4Hz)、θ (4-8Hz)、α (8-13Hz)、β (13-30Hz)、γ (30-45Hz) 频带
- 各频带功率数值显示

### 5. EDF 格式导出
- 支持导出为欧洲数据格式 (EDF)
- 兼容专业EEG分析软件

### 6. SQLite 模板数据库
- 存储癫痫波形模板数据
- 支持添加自定义模板

## 项目结构

```
├── app.py              # Flask 后端服务器
├── eeg_simulator.py    # EEG 波形模拟算法
├── eeg_analysis.py     # EEG 分析模块 (棘波检测、FFT)
├── database.py         # SQLite 数据库操作
├── edf_exporter.py     # EDF 格式导出模块
├── requirements.txt    # Python 依赖
├── templates/
│   └── index.html      # 前端界面
└── static/             # 静态资源目录
```

## 安装与运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

依赖包括:
- Flask (Web框架)
- numpy (数值计算)
- scipy (信号处理)
- pyedflib (EDF文件处理)

### 2. 运行服务器

```bash
python app.py
```

### 3. 访问应用

在浏览器中打开: `http://localhost:5000`

## 使用说明

1. **生成波形**: 选择脑电模式，点击"生成波形"按钮
2. **切换导联**: 点击上方的导联按钮切换显示不同通道
3. **手动标记**: 直接点击波形图标记可疑位置
4. **自动检测**: 点击"自动检测棘波"按钮进行模板匹配检测
5. **查看频谱**: 右侧面板实时显示当前导联的频率功率谱
6. **导出数据**: 点击"导出EDF"按钮保存为EDF格式文件

## 技术栈

- **后端**: Python + Flask
- **前端**: HTML5 + Canvas + JavaScript
- **数据处理**: NumPy + SciPy
- **数据库**: SQLite
- **文件格式**: EDF (European Data Format)
