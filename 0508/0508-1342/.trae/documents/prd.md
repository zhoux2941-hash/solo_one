## 1. 产品概述

历代地图绘制误差与疆域认知演变——一个交互式历史地图可视化平台，将唐、宋、元、明四朝的古地图疆域与现代中国地图叠加对比，通过色块可视化标示误差区域，帮助用户直观理解中国古代制图学的演进与局限。

- 目标用户：历史爱好者、地理教育工作者、制图学研究者
- 核心价值：以可视化方式呈现古代疆域认知的误差演变，让抽象的制图史变得可感知、可交互

## 2. 核心功能

### 2.1 功能模块

1. **地图主视图页**：现代中国底图 + 古代疆域叠加层 + 误差热力区域
2. **信息面板**：朝代误差来源分析、误差趋势对比

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 地图主视图 | 朝代选择器 | 唐/宋/元/明四朝切换按钮，选中态高亮，切换时地图平滑过渡 |
| 地图主视图 | 现代底图层 | 以SVG绘制现代中国行政区划轮廓作为底图 |
| 地图主视图 | 古代疆域叠加层 | 半透明色块显示所选朝代的疆域认知范围，与底图对比 |
| 地图主视图 | 误差热力层 | 误差大的区域以红色高亮，误差小以黄色过渡，无误差区域透明 |
| 地图主视图 | 图例面板 | 色块含义说明（精确/偏移/严重误差） |
| 信息面板 | 误差来源分析 | 列出该朝代三大误差来源：比例尺失调、方向偏差、山海经传统影响，含具体说明 |
| 信息面板 | 误差趋势图 | 四朝误差总体趋势柱状图/折线图，直观显示认知演变 |
| 信息面板 | 地图档案卡片 | 展示该朝代代表性地图名称、绘制年份、绘制者等信息 |

## 3. 核心流程

用户打开页面 → 看到现代中国底图 → 选择朝代（默认唐）→ 古代疆域叠加层淡入 → 误差区域以红/黄色块标示 → 右侧面板同步展示误差来源分析 → 切换朝代 → 地图叠加层平滑切换 → 观察误差变化趋势

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨色（#1a1a2e）为底，古铜金（#c9a96e）为点缀，朱砂红（#c23616）标记误差
- **辅助色**：宣纸白（#f5f0e8）、靛青（#2d6a4f）、藏蓝（#1d3557）
- **整体风格**：古舆图质感 × 现代数据可视化，融合传统水墨意境与精准信息设计
- **字体**：标题用衬线体（Noto Serif SC），正文用无衬线体（Noto Sans SC）
- **布局**：左侧大地图区域（约70%），右侧信息面板（约30%），顶部朝代选择栏

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 地图主视图 | 朝代选择器 | 横排标签式按钮，古铜金选中态，宣纸白默认态，悬停有墨晕效果 |
| 地图主视图 | 底图 + 叠加层 | SVG地图，古代疆域用半透明靛青/藏蓝色块，误差区用朱砂红渐变 |
| 地图主视图 | 图例 | 浮动小卡片，含色块说明与透明度示例 |
| 信息面板 | 误差来源 | 三栏卡片，每栏一个误差来源，含图标 + 标题 + 说明文字 |
| 信息面板 | 趋势图 | 简洁柱状图，四朝对比，柱体颜色随误差等级渐变 |
| 信息面板 | 地图档案 | 卡片式展示，含地图名称、年代、绘制者、缩略示意 |

### 4.3 响应式设计

- 桌面优先设计，大屏下左右分栏
- 平板以下切换为上下布局，地图在上，面板在下
- 朝代选择器在移动端变为底部固定横滑栏
