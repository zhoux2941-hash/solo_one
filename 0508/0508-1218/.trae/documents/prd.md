## 1. 产品概述

卫星轨道模拟工具是一款基于Web的3D交互式卫星轨道可视化与过境预测应用。用户可选择预置的10颗知名卫星（ISS、哈勃、北斗等），通过Three.js渲染3D地球与卫星轨道，实时显示卫星位置（经纬度、高度），并计算未来7天的过境预测（时间、方位角、仰角、亮度）。支持用户自定义观测位置和时间加速模拟。

- 目标用户：天文爱好者、卫星观测者、航天科普教育者
- 核心价值：将专业的卫星轨道计算以直观的3D可视化呈现，降低卫星观测门槛

## 2. 核心功能

### 2.1 功能模块

1. **3D轨道可视化页面**：3D地球渲染、卫星轨道绘制、卫星实时位置标记、时间加速控制
2. **卫星信息面板**：卫星选择、当前位置显示、轨道参数
3. **过境预测面板**：未来7天过境列表、方位角/仰角/亮度详情
4. **用户位置设置**：经纬度手动输入、地图点选定位

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页面 | 3D地球场景 | Three.js渲染地球模型，显示卫星轨道线与卫星位置标记，支持鼠标旋转/缩放 |
| 主页面 | 卫星选择面板 | 左侧面板，列出10颗预置卫星，点击选择后高亮其轨道 |
| 主页面 | 位置信息面板 | 右侧面板，显示选中卫星的实时经纬度、高度、速度 |
| 主页面 | 过境预测面板 | 右侧面板，显示未来7天每日过境时间、方位角、仰角、亮度 |
| 主页面 | 用户位置设置 | 底部/侧边弹窗，支持经纬度输入和简易地图点选 |
| 主页面 | 时间控制栏 | 底部控制栏，支持1x/10x/100x/1000x时间加速，暂停/播放切换 |

## 3. 核心流程

用户打开应用 → 选择卫星 → 3D场景展示卫星轨道与位置 → 查看实时经纬度/高度 → 设置观测位置 → 查看过境预测 → 使用时间加速观察卫星运动

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空黑 (#0a0e1a) 为背景，搭配星蓝 (#00d4ff) 作为强调色，地球绿 (#00ff88) 作为辅助色
- **按钮风格**：圆角半透明玻璃态按钮，带微光边框
- **字体**：Orbitron（科技感展示字体）+ Source Sans 3（信息阅读字体）
- **布局风格**：3D场景全屏铺底，左右侧半透明浮动面板，底部控制栏
- **图标风格**：线性简约科技风格图标（Lucide Icons）
- **整体风格**：深空科技风 / 太空指挥中心美学

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主页面 | 3D地球场景 | 全屏Three.js画布，星空背景粒子，地球自转，卫星轨道线（半透明渐变色），卫星标记（发光点） |
| 主页面 | 卫星选择面板 | 左侧半透明面板，卫星名称列表带国家/类型标签，选中项高亮发光边框 |
| 主页面 | 位置信息面板 | 右侧上方卡片，经纬度/高度/速度数值大字显示，带单位标签 |
| 主页面 | 过境预测面板 | 右侧下方可滚动列表，每日折叠卡片，展开显示详细过境数据表格 |
| 主页面 | 用户位置设置 | 弹窗式，含简易2D世界地图（SVG/Canvas），经纬度输入框，地图上标记点 |
| 主页面 | 时间控制栏 | 底部居中浮动栏，播放/暂停按钮，速度档位按钮组，当前模拟时间显示 |

### 4.3 响应式设计

- 桌面优先设计，3D场景占满视口
- 面板可折叠，小屏幕时自动收起
- 触摸设备支持手势旋转/缩放

### 4.4 3D场景指导

- **环境**：深空背景，星空粒子系统，微弱环境光
- **灯光**：太阳方向光（模拟太阳照射），微弱环境光
- **相机**：透视相机，初始视角斜上方俯视地球，支持OrbitControls交互
- **构图**：地球居中，卫星轨道环绕，视觉焦点在卫星当前位置
- **交互**：鼠标拖拽旋转，滚轮缩放，点击卫星标记显示详情
- **后处理**：可选Bloom效果（卫星发光），地球大气层辉光效果
