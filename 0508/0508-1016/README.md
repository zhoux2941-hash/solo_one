# WebRTC 实时导播台

基于WebRTC的实时视频导播台应用，支持多摄像头输入、画面切换、画中画、淡入淡出过渡、录制和推流。

## 功能特性

- ✅ **多输入源支持**：最多4个视频输入源（USB摄像头 + 屏幕共享）
- ✅ **实时预览**：每路输入实时缩略图预览
- ✅ **一键切换**：点击预览画面即可切换主输出
- ✅ **画中画效果**：主画面 + 小窗叠加，支持拖拽移动
- ✅ **淡入淡出过渡**：可配置的平滑切换效果（默认500ms）
- ✅ **本地录制**：支持WebM格式录制
- ✅ **RTMP推流**：支持推流到媒体服务器
- ✅ **监控窗口**：独立的实时监控窗口
- ✅ **低延迟切换**：使用Canvas渲染，切换延迟<100ms

## 使用方法

### 启动方式

由于WebRTC需要安全上下文（HTTPS或localhost），请使用以下方式之一启动：

#### 方式1：Python HTTP服务器
```bash
# Python 3
python -m http.server 8080
```

#### 方式2：Node.js HTTP服务器
```bash
npx http-server -p 8080
```

然后在浏览器中访问：`http://localhost:8080`

### 操作说明

1. **添加输入源**
   - 点击「添加摄像头」选择USB摄像头
   - 点击「屏幕共享」选择要共享的屏幕或窗口

2. **切换主画面**
   - 直接点击左侧任意预览窗口即可切换为主输出
   - 切换时会有淡入淡出过渡效果

3. **画中画模式**
   - 点击「画中画」按钮开启
   - **Ctrl+点击**预览窗口可设置为画中画源
   - 拖拽小窗口可移动位置
   - 点击小窗口上的「⇄」按钮可与主画面交换
   - 点击「✕」按钮关闭画中画

4. **录制功能**
   - 点击「开始录制」按钮开始录制
   - 再次点击停止录制，视频会自动下载为WebM文件

5. **推流功能**
   - 点击「开始推流」按钮
   - 输入RTMP推流地址（如：`rtmp://localhost/live/stream`）
   - *注意：实际推流需要配合媒体服务器使用*

6. **监控窗口**
   - 点击「监控窗口」打开独立的监控画面
   - 监控窗口显示当前主输出内容

### 过渡效果设置

- 勾选「淡入淡出过渡」启用/禁用过渡效果
- 滑动「过渡时长」滑块调整过渡时间（100ms - 2000ms）

## 模块说明

- **videoSourceManager.js**：视频源管理，负责摄像头和屏幕共享的采集
- **switcher.js**：画面切换器，使用Canvas渲染，实现淡入淡出过渡
- **pipManager.js**：画中画管理，支持拖拽和交换
- **recorder.js**：录制和推流管理
- **monitor.js**：独立监控窗口
- **app.js**：主应用入口，整合所有模块

## 浏览器兼容性

- Chrome 90+ (推荐)
- Firefox 88+
- Edge 90+
- Safari 14+

## 注意事项

1. 首次使用需要授权摄像头和屏幕共享权限
2. 屏幕共享功能在某些浏览器中需要HTTPS环境
3. RTMP推流需要配合媒体服务器（如Janus、MediaSoup、Wowza等）
4. 建议使用Chrome浏览器以获得最佳性能

## 系统要求

- CPU：Intel Core i5 或以上
- 内存：8GB RAM 或以上
- 摄像头：USB 2.0 或以上
- 操作系统：Windows 10/11, macOS 10.15+, Linux
