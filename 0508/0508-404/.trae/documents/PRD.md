## 1. 产品概述
中国高速公路服务区设施查询系统，面向长途驾驶者和物流从业者，提供直观的高速公路服务区设施信息查询与筛选服务，解决出行中"下一个服务区有什么"的信息痛点，提升出行规划效率。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 浏览地图、查询设施、筛选、搜索、收藏 |
| 高级用户 | 本地存储标记 | 同步收藏记录、个性化偏好 |

### 2.2 功能模块
1. **地图主页**: 高速公路简图展示、服务区标记点、设施筛选、交互点击
2. **服务区详情面板**: 设施信息展示、收藏操作
3. **高速搜索面板**: 按高速名称搜索、服务区列表与距离展示
4. **收藏管理面板**: 收藏列表、快速跳转

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 地图主页 | 高速公路简图 | 展示G4京港澳、G2京沪、G5京昆、G15沈海、G30连霍、G50沪渝共6条主线，标注服务区位置 |
| 地图主页 | 设施筛选栏 | 勾选设施类型（加油站、充电桩、餐厅、卫生间、母婴室、汽修点），实时过滤地图标记 |
| 地图主页 | 服务区标记点 | 点击标记点弹出简要信息，右侧面板展示详细设施 |
| 服务区详情面板 | 设施列表 | 展示该服务区所有设施类型与状态（可用/不可用），支持收藏操作 |
| 高速搜索面板 | 搜索输入框 | 输入高速名称（如"G4"），列出该高速全部服务区及距起点距离 |
| 收藏管理面板 | 收藏列表 | 展示已收藏服务区，点击可定位到地图对应位置 |

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深青色(#0F4C5C)为底，配合琥珀色(#E36414)高亮标记，传达道路与旅途意象
- **辅助色**: 浅灰蓝(#E0E8EF)背景区域，白色卡片，暗金色(#9A8C4C)图标点缀
- **按钮风格**: 圆角6px，微阴影，悬停时琥珀色发光效果
- **字体**: 标题使用 Noto Serif SC 衬线体，正文使用 Noto Sans SC，数字使用 DM Mono 等宽体
- **布局**: 左侧70%地图区 + 右侧30%信息面板，顶部筛选条，底部搜索栏
- **图标**: 线性风格(Icons8/Phosphor风格)，设施图标用不同颜色区分

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 地图主页 | 高速简图 | SVG路径绘制高速线路，渐变色区分不同高速，服务区用圆形标记，悬停放大动画 |
| 地图主页 | 设施筛选栏 | 顶部水平排列6个筛选标签(带图标)，勾选态填充琥珀色，取消态描边灰色 |
| 服务区详情面板 | 设施卡片 | 右侧滑出面板，服务区名称+所属高速，设施以图标+文字网格排列，可用绿色、不可用灰色 |
| 高速搜索面板 | 搜索结果 | 搜索框+结果列表，每行显示服务区名称+距起点公里数，点击行项地图定位 |
| 收藏管理面板 | 收藏卡片 | 底部浮动按钮触发，卡片式展示收藏服务区，含快速定位和取消收藏操作 |

### 4.3 响应式
- 桌面端优先(1920×1080)，地图占主体
- 平板端(768px)右侧面板变为底部抽屉
- 移动端(375px)全屏地图+浮动操作按钮，面板覆盖展示

### 4.4 动效设计
- 地图加载：高速线路从起点到终点逐段绘制动画(stroke-dashoffset)
- 服务区标记：脉冲呼吸动画(attention pulse)，点击时弹跳反馈
- 面板展开：从右侧滑入(slide-in)配合背景遮罩渐显
- 筛选切换：不符合条件的标记淡出缩小，符合条件的标记弹入
- 收藏操作：心形图标填充动画 + 粒子散开效果
