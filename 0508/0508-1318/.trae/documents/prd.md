## 1. 产品概述

瓦当拓片反转工具是一款面向考古学者、文物修复师和汉文化爱好者的专业工具应用。用户上传汉代瓦当拓片图像（黑白），系统可将阳纹反转为阴纹（模拟拓包拓印的翻转效果）或反之，帮助用户从不同视角观察瓦当纹饰。系统内置汉代瓦当纹饰数据库，可根据反转后清晰的纹饰特征推荐可能的瓦当类型与年代区间（西汉/东汉），并支持边缘增强滤镜和高清导出。

- 目标用户：考古研究者、文物修复师、博物馆工作人员、汉文化爱好者
- 核心价值：以数字化手段辅助瓦当拓片研究，降低纹饰辨识门槛，提升考古工作效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 上传图片、反转处理、边缘增强、纹饰推荐、导出高清图 |

### 2.2 功能模块

1. **主页面**：图片上传、双栏对比视图、反转控制、边缘增强滤镜、纹饰推荐面板、导出功能

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 图片上传区 | 支持拖拽/点击上传瓦当拓片图片（PNG/JPG/BMP），实时预览 |
| 主页面 | 双栏对比视图 | 左侧显示原图，右侧显示反转后图像，支持同步缩放与平移 |
| 主页面 | 反转控制栏 | 一键阳纹→阴纹/阴纹→阳纹切换，反转强度微调滑块 |
| 主页面 | 边缘增强滤镜 | Sobel/Laplacian边缘检测选择，增强强度滑块，实时预览 |
| 主页面 | 纹饰推荐面板 | 根据反转后纹饰特征，推荐瓦当类型（云纹/文字/四神纹等）、年代区间（西汉/东汉）、置信度 |
| 主页面 | 导出功能区 | 导出反转后高清PNG图，支持叠加边缘增强效果导出 |

## 3. 核心流程

用户打开应用 → 上传瓦当拓片图像 → 系统自动检测阳纹/阴纹 → 用户确认或切换反转方向 → 系统执行图像反转 → 双栏对比展示原图与反转图 → 用户可开启边缘增强滤镜突显纹饰细节 → 系统分析纹饰特征并推荐瓦当类型与年代 → 用户导出满意的高清反转图

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深沉墨色（#1a1a2e）为底，古铜金（#c9a96e）为点缀，宣纸白（#f5f0e8）为内容区
- **辅助色**：朱砂红（#c0392b）用于强调按钮，靛青（#2c5f7c）用于信息提示
- **字体**：标题使用 Noto Serif SC（宋体韵味），正文使用 Noto Sans SC
- **布局风格**：沉浸式暗色背景，中央双栏画布对比，底部控制栏，右侧推荐面板
- **图标风格**：线性图标，线宽1.5px，古铜金色
- **纹理背景**：微妙的宣纸纹理叠加，营造传统拓片鉴赏氛围

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 图片上传区 | 虚线边框拖拽区域，居中毛笔图标，淡金提示文字，拖入时高亮 |
| 主页面 | 双栏对比视图 | 左右等宽画布，半透明分隔线，底部缩放控制条，图像自适应居中 |
| 主页面 | 反转控制栏 | 底部固定栏，反转方向切换按钮（阳→阴/阴→阳），反转强度滑块 |
| 主页面 | 边缘增强滤镜 | 控制栏内嵌，算法下拉选择（Sobel/Laplacian），强度滑块，开关按钮 |
| 主页面 | 纹饰推荐面板 | 右侧抽屉式面板，推荐卡片列表，每卡片含类型图标、名称、年代、置信度进度条 |
| 主页面 | 导出功能区 | 控制栏右侧，导出按钮带下载图标，格式选择下拉 |

### 4.3 响应式设计

- 桌面端优先（1440px+）：双栏横向对比，右侧推荐面板常驻
- 平板端（768px-1440px）：双栏对比缩小，推荐面板改为底部弹出
- 移动端（<768px）：单栏切换对比，推荐面板全屏弹出
