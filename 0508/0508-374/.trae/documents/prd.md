# 摩尔密码加解密与训练工具 - PRD文档

## 1. 产品概述

### 1.1 产品名称
摩尔密码（摩尔斯电码）加解密与训练工具

### 1.2 产品定位
一个基于Web的摩尔斯电码学习和实践工具，帮助用户学习、练习和使用摩尔斯电码。

### 1.3 核心价值
- 提供中英文文本与摩尔斯电码的互转功能
- 通过音频播放帮助用户熟悉摩尔斯电码的声音特征
- 提供训练模式帮助用户提升听辨能力
- 实时统计训练成果，激励学习进度

---

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 文本转摩尔斯电码（编码）
- **输入**: 用户输入中英文文本
- **输出**: 对应的摩尔斯电码（使用点·划·表示）
- **特点**: 实时转换，输入即显示结果

#### 2.1.2 摩尔斯电码转文本（解码）
- **输入**: 用户输入摩尔斯电码（使用点·划·空格）
- **输出**: 对应的中英文文本
- **特点**: 实时解码，支持多种输入格式

#### 2.1.3 音频播放功能
- **功能**: 将摩尔斯电码转换为音频播放
- **速度调节**: 支持5-20 WPM（每分钟词数）
- **频率自定义**: 点划频率可自定义（默认800Hz）
- **技术**: 使用Web Audio API实现

#### 2.1.4 训练模式
- **随机生成**: 随机播放一段摩尔斯电码
- **用户输入**: 用户听到后输入对应字符
- **实时评分**: 系统即时判断对错并评分
- **统计功能**: 实时显示成功率统计

### 2.2 用户体验
- 响应式设计，支持桌面和移动设备
- 简洁直观的操作界面
- 流畅的动画效果
- 清晰的视觉反馈

---

## 3. 非功能需求

### 3.1 性能要求
- 响应时间 < 100ms
- 音频播放无延迟
- 支持离线使用

### 3.2 兼容性
- 支持主流浏览器（Chrome, Firefox, Safari, Edge）
- 支持移动端浏览器

---

## 4. 技术方案

### 4.1 技术栈
- **前端框架**: React + TypeScript
- **UI样式**: TailwindCSS 3
- **音频**: Web Audio API
- **状态管理**: React Hooks

### 4.2 数据结构

#### 4.2.1 摩尔斯电码映射表
```typescript
interface MorseCodeMap {
  [key: string]: string; // 字符 -> 摩尔斯电码
}
```

#### 4.2.2 训练状态
```typescript
interface TrainingState {
  score: number;      // 得分
  total: number;      // 总题数
  correct: number;    // 正确数
  successRate: number; // 成功率
}
```

### 4.3 核心功能实现

#### 4.3.1 编码算法
- 将输入文本转换为大写
- 根据映射表逐字符转换
- 字符间用空格分隔，单词间用斜杠分隔

#### 4.3.2 解码算法
- 按空格分割输入
- 根据映射表反向查找对应字符

#### 4.3.3 音频合成
- 使用Web Audio API创建振荡器
- 根据WPM计算点划时长
- 点: 1单位时间
- 划: 3单位时间
- 字符间隔: 1单位时间
- 单词间隔: 7单位时间

### 5.1 页面结构

- **主内容区**:

  - 题目显示
  - 答案输入
  - 统计信息展示

### 5.2 设计风格
- **主题**: 科技感、复古无线电风格
- **配色**: 深色背景，绿色/蓝色高亮
- **字体**: 等宽字体，模拟电码终端效果

## 6. 交互流程

### 6.1 编码流程
1. 用户选择"编码"模式
2. 用户输入文本
3. 实时显示摩尔斯电码
4. 点击播放按钮播放音频

### 6.2 解码流程
1. 用户选择"解码"模式
2. 用户输入摩尔斯电码
3. 实时显示解码文本

### 6.3 训练流程
1. 用户选择"训练"模式
2. 点击开始按钮，系统播放随机字符
3. 用户输入答案
4. 系统判断并更新统计
5. 重复步骤2-4

---

## 7. 数据统计

### 7.1 训练统计指标
- 总答题数
- 正确数
- 错误数
- 成功率百分比
- 连续正确数

### 7.2 数据持久化
- 使用localStorage保存训练记录
- 下次访问自动加载历史统计

### 10.2 WPM计算说明
- 标准摩尔斯电码速度以WPM（Words Per Minute）衡量
- 一个"词"定义为5个字符（PARIS）
- 1 WPM = 每分钟发送5个字符
