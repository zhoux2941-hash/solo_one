## 1. 产品概述
括号匹配深度计算器是一个纯前端工具应用，用于验证括号字符串的合法性并计算最大嵌套深度。面向开发者、编程学习者和算法爱好者，提供直观的括号匹配可视化体验。

## 2. 核心功能

### 2.1 功能模块
1. **主页面**：括号输入、匹配计算、结果展示

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 输入区域 | 文本输入框，仅接受括号字符 `{ } [ ] ( )`，支持实时输入过滤或提示 |
| 主页面 | 计算按钮 | 点击触发匹配算法，计算合法性与最大深度 |
| 主页面 | 结果展示 | 显示匹配结果（合法/非法）和最大嵌套深度值 |
| 主页面 | 示例快捷 | 提供快捷示例按钮，一键填入典型括号组合 |

## 3. 核心流程

用户在输入框中输入括号字符串，点击"计算"按钮后，系统使用栈算法验证括号匹配合法性：遍历每个字符，遇到左括号入栈并更新当前深度，遇到右括号检查栈顶是否为对应左括号，若不匹配则判定非法。遍历结束后若栈非空也判定非法。合法时返回最大深度值，非法时提示"不匹配"。

```mermaid

    "用户输入括号字符串" --> "点击计算按钮"
    "点击计算按钮" --> "执行匹配算法"
    "执行匹配算法" --> "遍历字符"
    "遍历字符" --> "左括号？"
    "左括号？" -->|"是"| "入栈，更新深度"
    "左括号？" -->|"否"| "检查栈顶匹配"
    "检查栈顶匹配" -->|"匹配"| "出栈，恢复深度"
    "检查栈顶匹配" -->|"不匹配"| "返回：非法"
    "入栈，更新深度" --> "遍历字符"
    "出栈，恢复深度" --> "遍历字符"
    "遍历字符" -->|"遍历结束"| "栈为空？"
    "栈为空？" -->|"是"| "返回：合法 + 最大深度"
    "栈为空？" -->|"否"| "返回：非法"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色系背景（深灰/近黑）+ 亮绿/青色强调色，呈现终端/代码编辑器氛围
- 辅助色：橙色用于警告/非法状态，绿色用于合法状态
- 按钮风格：圆角，带微妙发光效果
- 字体：等宽字体（JetBrains Mono / Fira Code）用于括号展示，无衬线字体用于说明文字
- 布局风格：居中卡片式，带有代码编辑器风格的边框和装饰
- 动画：括号输入时的打字效果、结果出现时的渐入动画、深度可视化的层叠展示

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主页面 | 输入区域 | 深色背景文本框、等宽字体、光标闪烁效果、行号装饰 |
| 主页面 | 计算按钮 | 圆角按钮、hover 发光、点击波纹 |
| 主页面 | 结果展示 | 合法=绿色徽章+深度数字、非法=橙色徽章+错误提示、渐入动画 |
| 主页面 | 示例快捷 | 小型标签按钮组、hover 变色 |

### 4.3 响应式
桌面优先，移动端自适应。卡片宽度最大 640px，居中展示。
