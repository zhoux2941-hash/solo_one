## 1. 产品概述

古代度量衡单位换算与器物尺寸推定系统——面向历史研究者、考古工作者及中国传统文化爱好者，提供历代度量衡单位精确换算与考古器物尺寸逆向推算功能。

- 解决跨朝代度量衡单位换算困难、器物尺寸与古代单位对应关系不直观的问题
- 为学术研究与文化传播提供权威、直观、可交互的度量衡换算工具

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 使用全部换算与推定功能、收藏换算结果 |
| 学者用户 | 无需注册 | 同上，导出换算数据 |

### 2.2 功能模块

1. **度量衡对照表页**: 历代度量衡单位对照表、朝代选择器、单位类别切换（长度/容量/重量）
2. **单位换算工具页**: 数值输入、来源朝代与目标朝代选择、实时换算结果、收藏功能
3. **器物尺寸推定页**: 器物类型选择、典型尺寸展示、尺寸调节器、反向推算古代单位值、收藏功能

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 度量衡对照表 | 朝代时间轴 | 横向展示周至清七个朝代，点击切换查看对应度量衡数据 |
| 度量衡对照表 | 单位类别切换 | 长度（尺/寸/丈）、容量（升/斗/斛）、重量（斤/两/铢）三类切换 |
| 度量衡对照表 | 对照表主体 | 显示各朝代1尺=?cm、1升=?ml、1斤=?g等换算值，高亮当前选中朝代 |
| 度量衡对照表 | 直观对比图 | 以条形图/比例尺直观展示各朝代同一单位的实际长度/容量/重量差异 |
| 单位换算工具 | 数值输入区 | 输入框+单位下拉（尺/寸/丈/升/斗/斛/斤/两/铢）+来源朝代选择 |
| 单位换算工具 | 目标选择区 | 目标朝代选择（可多选对比）、厘米/毫升/克现代单位换算 |
| 单位换算工具 | 结果展示区 | 显示"汉10尺=231cm=唐9.7尺"格式结果，支持一键复制 |
| 单位换算工具 | 收藏按钮 | 将常用换算结果加入收藏列表 |
| 器物尺寸推定 | 器物选择器 | 下拉/卡片选择器物类型（战国铜鼎、汉代铜镜、唐代三彩马等） |
| 器物尺寸推定 | 典型尺寸展示 | 显示该器物考古典型尺寸范围（高、口径、腹径等），含数据来源标注 |
| 器物尺寸推定 | 尺寸调节器 | 滑块+输入框调节各维度尺寸，实时更新 |
| 器物尺寸推定 | 反向推算结果 | 根据调节后的尺寸，反向推算对应各朝代单位值（如"高=周2.3尺=汉2.1尺"） |
| 器物尺寸推定 | 收藏按钮 | 将推定结果加入收藏列表 |
| 全局 | 收藏面板 | 侧边栏/弹出面板展示所有收藏的换算结果，支持删除与一键重新换算 |

## 3. 核心流程

**单位换算流程**: 用户输入数值→选择单位与来源朝代→选择目标朝代→系统计算并展示结果→用户可收藏结果

**器物推定流程**: 用户选择器物类型→系统展示典型尺寸范围→用户可调节尺寸→系统反向推算古代单位值→用户可收藏结果

```mermaid
flowchart TD
    "用户进入系统" --> "浏览对照表"
    "浏览对照表" --> "单位换算"
    "浏览对照表" --> "器物推定"
    "单位换算" --> "输入数值+选择单位+来源朝代"
    "输入数值+选择单位+来源朝代" --> "选择目标朝代"
    "选择目标朝代" --> "展示换算结果"
    "展示换算结果" --> "收藏结果"
    "器物推定" --> "选择器物类型"
    "选择器物类型" --> "展示典型尺寸"
    "展示典型尺寸" --> "调节尺寸"
    "调节尺寸" --> "反向推算古代单位"
    "反向推算古代单位" --> "收藏推定结果"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 墨色(#1a1a2e)与宣纸色(#f5f0e8)对比，朱砂红(#c23616)为点缀色，辅以青铜绿(#2d6a4f)
- **按钮风格**: 圆角矩形，朱砂红主按钮，宣纸色次按钮带墨色边框，hover时微微上浮+阴影加深
- **字体**: 标题使用"ZCOOL XiaoWei"(站酷小薇体)或"Ma Shan Zheng"(马善政楷体)体现古风，正文使用"Noto Serif SC"宋体风格保证可读性
- **布局风格**: 顶部导航栏+标签页切换三大功能区，内容区居中宽幅布局，侧边收藏面板
- **图标/纹饰**: 使用祥云纹、回纹等传统纹饰作为装饰边框与分隔线，朝代图标采用对应朝代代表纹样

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 度量衡对照表 | 朝代时间轴 | 横向滚动时间轴，每个朝代节点含圆形图标+朝代名，选中态朱砂红高亮，过渡动画 |
| 度量衡对照表 | 对照表主体 | 卡片式表格，宣纸色背景带水印纹理，数据居中对齐，选中行朱砂红左边框 |
| 度量衡对照表 | 直观对比图 | 水平条形图，青铜绿渐变填充，刻度标注厘米/毫升/克 |
| 单位换算工具 | 数值输入区 | 大号输入框居中，单位与朝代下拉选择器并排，朱砂红聚焦边框 |
| 单位换算工具 | 结果展示区 | 大字展示换算公式，含动画数字跳动效果，目标朝代结果以卡片排列 |
| 器物尺寸推定 | 器物选择器 | 网格卡片布局，每张卡片含器物线稿图标+名称，选中态朱砂红边框 |
| 器物尺寸推定 | 尺寸调节器 | 自定义滑块（青铜绿轨道+朱砂红滑块），右侧实时数值输入框 |
| 器物尺寸推定 | 反向推算结果 | 纵向排列各朝代对应值，每位数值含小型朝代标签，淡入动画 |

### 4.3 响应式设计

- 桌面优先设计，内容区最大宽度1200px
- 平板端：时间轴横向滚动，卡片2列布局
- 移动端：单列布局，时间轴改为纵向，收藏面板改为底部弹出
