# 系统架构设计

## 概述
企业级订单管理系统采用前后端分离架构，支持多租户、微前端、响应式设计等企业级特性。

## 技术栈

### 后端技术栈
- **框架**: Spring Boot 3.x
- **数据库**: H2 (可切换 MySQL/PostgreSQL)
- **认证**: JWT
- **API**: RESTful + GraphQL
- **WebSocket**: STOMP 协议
- **分布式事务**: Seata (预留)
- **全链路追踪**: SkyWalking (预留)

### 前端技术栈
- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **UI组件库**: Ant Design 5
- **状态管理**: Zustand
- **路由**: React Router 6
- **图表**: ECharts
- **国际化**: i18next
- **微前端**: 基于路由的微前端架构

## 架构设计

### 1. 多租户架构
```
┌─────────────────────────────────┐
│      API Gateway / 路由层        │
└──────────────┬──────────────────┘
               │
    ┌──────────▼──────────┐
    │  Tenant Context      │
    │  租户上下文过滤器    │
    └──────────┬──────────┘
               │
    ┌──────────▼──────────┐
    │  业务逻辑层          │
    │  (订单/商品/财务)    │
    └──────────┬──────────┘
               │
    ┌──────────▼──────────┐
    │  数据访问层          │
    │  按tenant_id隔离     │
    └─────────────────────┘
```

### 2. 微前端架构
```
              ┌─────────────────┐
              │   Main App      │
              │   (主应用)       │
              │  - 登录/鉴权     │
              │  - 布局/菜单     │
              │  - 状态管理      │
              └────────┬────────┘
                       │
        ┌──────────────┼──────────────┐
        │              │              │
   ┌────▼───┐     ┌───▼────┐    ┌────▼───┐
   │ Order  │     │ Product│    │ Finance│
   │ 子应用  │     │ 子应用  │    │ 子应用  │
   │ 订单    │     │ 商品    │    │ 财务    │
   └────────┘     └────────┘    └────────┘
```

## 核心功能模块

### 1. 订单管理
- 订单创建/编辑
- 多级审批流程
- 订单取消/退款
- 订单状态追踪
- 订单导出

### 2. 商品管理
- SKU管理
- 库存同步
- 价格策略(阶梯价/会员价/时间价)
- 商品分类
- 库存预警

### 3. 财务报表
- 月度/年度报表
- 同比/环比分析
- Excel/PDF导出
- 营收趋势图
- 成本利润分析

### 4. 权限系统
- RBAC权限模型
- 部门级联权限
- 页面级权限控制
- 按钮级权限控制
- 数据权限隔离

### 5. 消息通知
- WebSocket实时推送
- 邮件通知
- 短信通知
- 站内消息

### 6. 数据看板
- ECharts可视化图表
- 拖拽自定义布局
- 多维度数据分析
- 实时数据更新

## 安全设计

### 1. 认证
- JWT Token 认证
- Token 刷新机制
- 登录失败锁定

### 2. 授权
- 基于角色的访问控制(RBAC)
- 接口权限校验
- 数据权限隔离(tenant_id)

### 3. 数据安全
- 密码加密存储(BCrypt)
- 敏感数据脱敏
- SQL注入防护
- XSS防护

## 性能优化

### 后端
- 数据库索引优化
- Redis缓存(预留)
- 异步处理(@Async)
- 分页查询

### 前端
- 路由懒加载
- 组件按需加载
- 虚拟列表
- 离线缓存(Service Worker)
- IndexedDB本地存储
