## 2. 技术描述
- 前端：React@18 + TypeScript + Vite
- 样式：TailwindCSS@3
- 图形绘制：Canvas 2D API
- 音频：Web Audio API
- 无后端，纯前端应用
- 状态管理：React useState/useReducer

| GibbsDisplay.tsx | 吉布斯现象数据展示 |

## 4. 波形类型定义

### 方波 Fourier Series
- 方波：f(x) = (4/π) * Σ(sin((2n-1)x/(2n-1)
- 三角波：f(x) = (8/π²) * Σ((-1)^((n-1)/2) * sin(nx)/n²)
- 锯齿波：f(x) = (2/π) * Σ(sin(nx)/n
