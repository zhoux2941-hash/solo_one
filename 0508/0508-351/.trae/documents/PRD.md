# 地铁检修联排台系统 PRD

## 1. 产品概述
地铁检修联排台是为地铁检修队设计的可视化调度工具，将轨旁传感器更换申请、断电窗口、班组进场和旧件回收四条业务线整合到一张时间轴表中，实现窗口调整的实时冲突检测，提高检修作业的安全性和效率。

### 1.1 产品背景
- **目标用户**：地铁检修调度员、工班长、现场作业人员
- **解决问题**：多条业务线独立排班导致的窗口冲突、信息不对称、作业安全隐患
- **核心价值**：可视化联排、实时冲突预警、规范化流程、可追溯记录

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 调度员 | 企业账号登录 | 调整窗口、查看全局、导出交接单 |
| 工班长 | 企业账号登录 | 查看排班、提交申请、确认进场 |
| 作业人员 | 企业账号登录 | 查看任务、更新状态、确认回收 |

### 2.2 功能模块
1. **联排台主界面**：时间轴视图、工点地图、冲突告警面板
2. **窗口管理**：断电窗口创建/调整、拖拽调整时间
3. **申请管理**：传感器更换申请、旧件回收申请
4. **班组管理**：进场排班、人员分配、状态追踪
5. **冲突检测**：实时冲突推算、告警提示、冲突详情
6. **班次交接**：交接单生成、历史记录、状态同步

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 联排台主页 | 时间轴视图 | 横向时间轴，纵向业务线，支持拖拽调整窗口 |
| 联排台主页 | 工点地图 | 地铁线路工点分布，点击查看详情和状态 |
| 联排台主页 | 冲突告警 | 实时显示冲突列表，高亮显示冲突工点 |
| 申请管理页 | 更换申请 | 传感器更换申请表单、审批流程 |
| 申请管理页 | 回收申请 | 旧件回收申请、回收确认 |
| 班组管理页 | 进场排班 | 班组人员管理、进场时间安排 |
| 交接单页 | 班次交接 | 交接班记录、任务移交、签字确认 |

## 3. 核心流程

### 3.1 窗口调整与冲突检测流程
1. 调度员在时间轴上拖拽调整断电窗口
2. 系统实时计算所有关联工点的时间重叠
3. 检测到冲突后立即在界面上高亮告警
4. 调度员查看冲突详情，决定调整方案
5. 确认后更新所有相关方的状态

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：工业蓝（#1E40AF）代表专业和可靠
- **辅助色**：告警红（#DC2626）表示冲突，成功绿（#059669）表示正常
- **字体**：使用 Inter 字体，清晰易读的工业风格
- **布局风格**：分栏布局，左侧功能导航，中间时间轴主区，右侧详情面板
- **图标风格**：使用线性图标，简洁专业

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|--------|
| 联排台主页 | 时间轴视图 | 横向时间刻度、可拖拽卡片、颜色编码业务线、冲突红色边框 |
| 联排台主页 | 工点地图 | 线路示意图、工点标记、状态颜色指示、悬浮提示 |
| 联排台主页 | 冲突告警 | 告警列表、冲突类型、影响范围、一键跳转 |
| 申请表单 | 表单组件 | 日期选择器、下拉选择、多级联动、提交按钮 |

### 4.3 响应式设计
- **桌面优先**：针对1920x1080及以上分辨率优化
- **平板适配**：支持平板横屏使用，保留核心功能
- **触摸优化**：拖拽区域设置最小触摸尺寸，确保操作精准

### 4.4 交互动效
- 窗口拖拽时的实时位置反馈
- 冲突检测时的脉冲告警动画
- 状态变更时的平滑过渡效果
- 页面加载时的骨架屏占位
