# 🏥 远程手术协作系统

基于 WebRTC 和 WebCodecs 构建的实时远程手术协作平台，支持4K视频传输、实时标注、双向语音和影像测量功能。

## ✨ 功能特性

### 📹 视频传输
- 支持 4K (3840x2160) @ 30fps 高清视频
- WebCodecs H.265 硬件加速编码
- WebRTC P2P 低延迟传输
- **智能带宽控制：4-15Mbps 可调，解决 >30Mbps 带宽过高问题**
- **自适应比特率调整：根据网络状况动态优化**

### ✏️ 实时标注
- 多种标注工具：箭头、圆圈、文字、测量
- 6种标注颜色可选
- 可调节线宽
- **DataChannel 低延迟优化：无序传输 + 零重传**
- **批量发送 + 二进制编码：标注同步误差 < 10ms**
- 标注同步误差 < 50ms

### 🎤 双向语音
- 实时语音通话
- 语音活动检测
- 低延迟音频传输

### 📐 影像测量
- 支持距离测量
- 自定义标定参考
- 毫米级精度显示
- 测量历史记录

### 📊 性能监控
- 端到端延迟显示（目标 < 200ms）
- 同步误差监控
- 比特率和帧率统计
- 网络质量指标
- 丢包率和RTT实时显示

## 🚀 快速开始

### 环境要求
- Node.js >= 18.0.0
- 支持 WebRTC 和 WebCodecs 的浏览器（Chrome 94+, Edge 94+, Safari 15.4+）

### 安装依赖
```bash
npm install
```

### 启动信令服务器
```bash
npm run server
```
服务器将在 `http://localhost:8080` 启动

### 启动开发服务器
```bash
npm run dev
```
应用将在 `http://localhost:3000` 启动

### 构建生产版本
```bash
npm run build
```

## 📖 使用说明

### 主刀端（医生）
1. 访问首页，点击"主刀端"
2. 选择摄像头设备和分辨率
3. **设置目标比特率：推荐 8-12Mbps 用于4K视频**
4. **开启带宽自适应：推荐开启以获得最佳体验**
5. 点击"开启摄像头"
6. 点击"创建房间"生成房间号
7. 将房间号分享给专家
8. 接收专家的实时标注指导

### 专家端
1. 访问首页，点击"专家端"
2. 输入主刀端提供的房间号
3. 点击"加入房间"
4. 选择标注工具开始绘图
5. 标注将实时同步到主刀端

### 影像测量
1. 在专家端点击"开始标定"
2. 在画面上拖动绘制已知长度的参考线
3. 输入参考线的实际长度（毫米）
4. 选择"测量"工具进行距离测量
5. 测量结果将自动显示并同步

## 🔧 性能优化说明

### 📡 带宽优化（解决 >30Mbps 过高问题）

1. **比特率限制**
   - 默认限制：8Mbps
   - 可选范围：4-15Mbps
   - 4K推荐：8-12Mbps
   - 1080p推荐：4-8Mbps

2. **自适应比特率算法**
   - 丢包率 >5%：降低 20% 比特率
   - 丢包率 2-5%：降低 5% 比特率
   - RTT <50ms 且丢包 <1%：逐步提高比特率

3. **WebRTC 编码参数优化**
   - 使用 RTCRtpSender.setParameters() 动态控制
   - maxBitrate 硬限制防止带宽溢出
   - SDP 后备方案确保兼容性

### ⚡ 标注同步优化（延迟 <50ms）

1. **DataChannel 配置优化**
   ```javascript
   ordered: false        // 无序传输，避免队头阻塞
   maxRetransmits: 0     // 零重传，降低延迟
   protocol: 'binary'    // 二进制协议
   ```

2. **批量发送机制**
   - 16ms 缓冲窗口收集标注
   - 合并多个标注为一个批量消息
   - 减少网络IO次数

3. **二进制编码压缩**
   - TextEncoder/TextDecoder 编码
   - 消息体压缩率提升约30%

4. **时间同步协议**
   - 2秒周期NTP风格时间同步
   - RTT往返时间计算
   - 时钟偏移补偿算法

## 🔧 技术架构

### 核心技术栈
- **WebRTC**: 实时音视频传输和数据通道
- **WebCodecs**: H.265 硬件加速视频编码
- **WebSocket**: 信令服务器通信
- **Canvas 2D**: 标注绘制和渲染
- **Vite**: 现代前端构建工具

### 延迟优化策略
1. **WebRTC 低延迟配置**:
   - `latencyMode: 'realtime'`
   - `bundlePolicy: 'max-bundle'`
   - `rtcpMuxPolicy: 'require'`

2. **DataChannel 优化**:
   - 无序传输 (`ordered: false`)
   - 零重传 (`maxRetransmits: 0`)
   - 二进制消息编码
   - 批量发送机制

3. **视频编码优化**:
   - 硬件加速优先
   - 动态比特率调整
   - 低延迟编码配置
   - maxBitrate 硬限制

4. **时间同步机制**:
   - 周期性 NTP 风格时间同步
   - RTT 往返时间计算
   - 时间戳补偿算法
