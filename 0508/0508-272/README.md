# 工控烧录调试工具

一款基于 Electron + Express 的纯离线桌面工控烧录调试工具。

## 功能特性

### 核心业务功能
1. **固件管理** - 本地导入 BIN/HEX 固件文件，自动识别版本和硬件型号
2. **批量烧录** - 串口自动扫描，支持一对一和多设备批量烧录
3. **实时监控** - 烧录进度可视化，成功/失败状态即时反馈
4. **串口调试** - 手动发送指令，自定义波特率，查看通信报文
5. **版本管理** - 固件多版本归档，支持历史版本回滚
6. **权限管理** - 用户权限划分，操作日志全程留存

### 技术特性
- 完全离线运行，无外网依赖
- 支持 Windows 工控电脑
- 最小化后台静默烧录
- 嵌入式 SQLite 数据库存储所有数据
- 串口扫描响应迅速
- 大批量烧录稳定无中断

## 数据库设计

### 主要数据表

1. **users** - 用户表

2. **firmware** - 固件表

5. **flash_records** - 烧录记录表
   - 存储每个设备的详细烧录记录

6. **operation_logs** - 操作日志表
   - 记录所有用户操作行为

7. **debug_logs** - 调试日志表
   - 记录串口通信数据

- **前端框架**: Electron + 原生 HTML/CSS/JS

## 批量异步烧录调度优化

### 全新调度引擎架构

采用全新的 `FlashScheduler` 调度引擎，实现真正的异步批量烧录：

#### 1. 核心调度功能

**并发控制:**
- 默认最大并发数: 5 个设备
- 超出设备进入队列等待
- 可通过配置动态调整

**队列管理:**
- FIFO 先进先出队列
- 空闲槽位自动分配
- 支持动态增减设备

**任务状态持久化:**
- 所有状态实时写入数据库
- 包含完整的重试记录
- 支持任务中断后恢复

#### 2. 串口通信异常自动重试

**三级重试机制:**

1. **数据发送重试** (`sendWithRetry`)
   - 单块数据发送失败自动重试
   - 最多重试 3 次
   - 每次重试间隔递增（500ms → 1s → 1.5s）

2. **串口连接重试** (`tryConnect`)
   - 串口连接失败自动重试
   - 最多重试 3 次
   - 每次重试间隔递增（1s → 2s → 3s）

3. **整设备烧录重试** (`handlePortRetry`)
   - 整设备烧录失败后自动重试
   - 重试前断开并重新建立连接
   - 最多重试 3 次（可配置）
   - 重试间隔可配置（默认 2s）

**可配置参数:**
```javascript
{
  maxConcurrent: 5,      // 最大并发数
  maxRetries: 3,         // 最大重试次数
  retryDelay: 2000,      // 重试间隔(ms)
  broadcastInterval: 100 // 状态广播间隔(ms)
}
```

#### 3. 失败设备手动重烧

**一键重试功能:**
- 烧录完成后显示"重试失败设备"按钮
- 仅针对失败/取消的设备重新烧录
- 成功设备不受影响
- 自动重置进度和错误信息

**重试状态显示:**
- 显示重试次数徽章（⟳ N）
- 重试中状态特殊颜色标识
- 完整的错误历史记录

## 串口设备识别增强功能

### 多设备精准识别策略

系统采用多级识别策略，确保多设备同时连接时能准确区分：

1. **优先级 1: 设备序列号 (Serial Number)**
   - 最可靠的设备唯一标识
   - 设备重新插拔端口变化仍能识别

2. **优先级 2: PNP ID**
   - Windows 系统特有即插即用 ID
   - 包含 VID/PID 和设备实例信息

3. **优先级 3: VID + PID 组合**
   - 厂商 ID + 产品 ID
   - 同型号多设备时作为辅助识别

4. **回退: 端口名称**
   - 无硬件标识时使用端口名
   - 设备插拔时可能变化

### 新功能特性

#### 1. 智能端口扫描
- 自动检测设备是否已注册
- 显示设备友好名称（型号 + 序列号）
- 颜色区分已知/未知设备
- 设备信息自动关联更新

#### 2. 一键设备注册
- 扫描时自动获取硬件信息
- 一键注册新设备到数据库
- 支持自定义硬件型号
- 自动记录所有硬件标识

#### 3. 多设备同时管理
- 可视化端口选择网格
- 实时显示选中设备数量
- 支持批量选择和操作
- 设备状态实时同步

## 固件解析增强功能

### 支持的文件格式
- **BIN 文件** - 原始二进制固件文件
- **HEX 文件** - Intel HEX 格式文件

### 增强的解析能力

1. **双重 HEX 解析**
   - 优先使用标准 Intel HEX 解析
   - 解析失败自动切换到增强容错解析
   - 支持校验和错误、格式不规范的文件

2. **加密固件检测**
   - 使用信息熵分析算法检测加密固件
   - 熵值 > 7.0 标记为可能已加密
   - 显示加密状态标识

3. **详细解析信息**
   - 解析方法（标准/增强）
   - 起始地址
   - 解析警告信息
   - MD5 校验和

### 数据库字段

固件表新增字段：
- `file_type` - 文件类型 (bin/hex)
- `start_address` - 起始地址
- `is_encrypted` - 是否加密
- `encryption_type` - 加密类型
- `parse_method` - 解析方法
- `warnings` - 解析警告信息
