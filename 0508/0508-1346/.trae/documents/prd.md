## 1. 产品概述

家庭开销分类统计是一款纯前端的家庭记账应用，帮助用户快速记录日常开销，并按月份和分类自动汇总支出数据，以可视化柱状图呈现消费趋势。目标用户为有家庭理财需求的普通用户，核心价值在于让家庭开销一目了然、预算有据可依。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 全部功能（添加开销、查看统计、设置预算） |

### 2.2 功能模块

1. **开销记录页**：添加开销记录（日期、金额、分类、备注），查看当月开销列表，支持删除记录
2. **统计概览页**：当月总支出、环比涨跌百分比、分类柱状图、月份切换器
3. **预算管理页**：为每个分类设置月预算，查看预算使用进度条，超预算提醒

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 开销记录页 | 添加开销表单 | 输入日期、金额、分类（餐饮/交通/购物/娱乐/医疗/教育）、备注，点击添加 |
| 开销记录页 | 开销列表 | 展示当月所有开销记录，按日期降序排列，支持删除 |
| 统计概览页 | 月度总览卡片 | 显示当月总支出金额、环比上月涨跌百分比（绿色下降/红色上升） |
| 统计概览页 | 分类柱状图 | 按分类显示当月各分类总支出柱状图，支持鼠标悬停查看具体金额 |
| 统计概览页 | 月份切换器 | 左右箭头切换月份，查看历史数据 |
| 预算管理页 | 预算设置 | 为每个分类输入月预算金额 |
| 预算管理页 | 预算进度条 | 展示各分类已花费/预算进度条，超预算时红色警示 |
| 预算管理页 | 预算提醒 | 超过预算80%时黄色警告，超过100%时红色警告弹窗提示 |

## 3. 核心流程

用户打开应用 → 查看当月总支出与环比 → 点击添加开销记录 → 填写日期/金额/分类/备注 → 保存至本地存储 → 自动更新统计图表 → 切换月份查看历史 → 设置分类预算 → 超预算时收到提醒

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橙色（#F97316）作为品牌色，搭配深灰色（#1E1E2E）背景与浅灰白（#F8F9FA）前景
- **辅助色**：各分类使用独立色彩标识（餐饮-橙色、交通-蓝色、购物-粉色、娱乐-紫色、医疗-绿色、教育-青色）
- **按钮风格**：圆角按钮（rounded-xl），主按钮填充暖橙色，次按钮描边
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular
- **布局风格**：单页应用，左侧导航栏 + 右侧内容区，卡片式布局
- **图标风格**：Lucide React 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 开销记录页 | 添加开销表单 | 卡片容器、日期选择器、金额输入框、分类下拉、备注文本框、提交按钮、暖橙色渐变 |
| 开销记录页 | 开销列表 | 卡片列表、每条记录显示分类色条+金额+备注、滑动删除、淡入动画 |
| 统计概览页 | 月度总览卡片 | 大号金额数字、环比箭头图标、绿色/红色涨跌指示、微妙背景渐变 |
| 统计概览页 | 分类柱状图 | 自定义柱状图组件、分类色彩映射、悬停tooltip、动画过渡 |
| 统计概览页 | 月份切换器 | 左右箭头按钮、当前月份文字、平滑过渡 |
| 预算管理页 | 预算设置 | 分类网格、每格含分类图标+输入框+保存按钮 |
| 预算管理页 | 预算进度条 | 渐变进度条、百分比文字、黄色80%预警、红色100%超标 |
| 预算管理页 | 预算提醒 | Toast通知弹出、红色警告弹窗 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1024px
- 平板适配：导航栏折叠为底部Tab栏
- 移动端适配：单列布局，底部Tab导航
