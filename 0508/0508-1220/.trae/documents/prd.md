## 1. 产品概述

心电图（ECG）模拟工具是一款专业的前端交互式医疗波形模拟应用，面向医学生、临床教学和医疗设备开发测试人员。
- 通过波形合成算法实时生成多种心律的模拟ECG信号，支持特征点标注与参数测量，提供直观的教学与调试体验
- 目标用户为医学教育场景中的师生，以及医疗设备前端开发者，产品价值在于零成本、零风险的ECG波形学习与验证环境

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 直接访问 | 选择心律类型、查看波形、导出导入数据 |
| 教学用户 | 直接访问 | 上述权限 + 特征点标注与参数查看 |

### 2.2 功能模块

1. **ECG模拟主页**: 心律类型选择、实时波形Canvas、特征点标注、参数悬停提示、心率节律统计、CSV导入导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| ECG模拟主页 | 心律类型选择器 | 支持切换正常窦性心律、窦性心动过速、窦性心动过缓、房颤四种模式 |
| ECG模拟主页 | 实时波形Canvas | Canvas绘制ECG波形，实时滚动显示，支持播放/暂停/速度调节 |
| ECG模拟主页 | 特征点标注 | 自动标注P波、QRS波群、T波位置，以不同颜色标记显示 |
| ECG模拟主页 | 波形参数悬停 | 鼠标悬停在波形上显示PR间期、QRS时限、QT间期等参数 |
| ECG模拟主页 | 心率节律统计 | 实时显示每分钟心跳数（BPM）、节律是否规整 |
| ECG模拟主页 | CSV导出 | 将当前波形数据导出为CSV文件（时间、电压两列） |
| ECG模拟主页 | CSV导入 | 导入外部ECG数据（CSV格式，两列：时间、电压），在Canvas上渲染 |

## 3. 核心流程

**主流程**: 用户进入页面 → 选择心律类型 → 系统实时生成对应ECG波形并滚动显示 → 用户可悬停查看参数、观察特征点标注 → 用户可导出数据或导入外部数据

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深色医疗监护仪风格（深黑底色 #0a0e17，荧光绿波形 #00ff88，配合暗青色UI元素 #1a2332）
- **辅助色**: 橙色警告/标注色 #ff6b35，蓝色信息色 #4ecdc4，红色异常色 #ff4757
- **按钮风格**: 圆角矩形，半透明背景 + 边框发光效果，hover时发光增强
- **字体**: 显示字体使用 JetBrains Mono（等宽，适合数据展示），UI字体使用 Noto Sans SC（中文支持）
- **布局风格**: 左侧控制面板 + 中央大面积Canvas波形区 + 底部统计条，医疗监护仪经典布局
- **图标风格**: Lucide线性图标，配合荧光绿色调

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| ECG模拟主页 | 心律类型选择器 | 左侧面板，4个单选按钮卡片，当前选中项带荧光绿边框发光 |
| ECG模拟主页 | 实时波形Canvas | 中央区域，深黑背景+荧光绿网格线+绿色波形线，支持缩放 |
| ECG模拟主页 | 特征点标注 | Canvas上层叠加，P波黄色三角标记、QRS红色菱形标记、T波蓝色圆点标记 |
| ECG模拟主页 | 波形参数悬停 | 跟随鼠标的半透明黑色提示框，等宽字体显示参数数值 |
| ECG模拟主页 | 心率节律统计 | 底部统计条，大字号BPM数值 + 节律状态指示灯（绿=规整/红=不规整） |
| ECG模拟主页 | CSV导入导出 | 左侧面板按钮，带文件图标，导入时显示文件选择对话框 |
| ECG模拟主页 | 播放控制 | 左侧面板，播放/暂停按钮、速度滑块 |

### 4.3 响应式设计

- 桌面优先设计，Canvas区域自适应占满可用空间
- 最小支持1280px宽度，低于此宽度时控制面板折叠为顶部工具栏
- Canvas始终占满视口主区域，确保波形可读性

### 4.4 3D场景指引

- 不适用
