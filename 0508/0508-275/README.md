# 3D分子结构可视化工具 - 高性能版

基于WebGL（Three.js）的高性能3D分子结构可视化工具，支持PDB格式，特别优化了大分子（如核糖体，20万+原子）的渲染性能。

## 性能优化特性

### 加载性能优化（解决8秒卡顿问题）
1. **分块数据处理**：原子/化学键数据分块计算，每块后释放主线程
   - 原子：5000个/块
   - 化学键：3000个/块
   - 每块间1ms间隔让浏览器响应UI

2. **异步渲染**：使用Promise/async异步构建几何体，不阻塞主线程

3. **实时进度条**：加载全程显示进度条和状态文字，让用户感知进度

4. **Gzip压缩**：后端自动检测Accept-Encoding头，返回gzip压缩的JSON
   - 3万原子数据：约10MB → 压缩后约1.5MB（-85%）
   - 数据传输时间减少80%+

5. **预分配TypedArray**：提前分配Float32Array存储矩阵和颜色数据，减少GC

### 前端渲染优化
1. **单InstancedMesh + 顶点颜色**：所有原子使用一个实例化网格，配合顶点颜色，减少Draw Call
2. **几何体全局缓存**：Sphere和Cylinder几何体全局缓存，避免重复创建
3. **LOD多级细节**：根据距离和原子数自动切换
   - 超高质量：<40Å，完整细节
   - 超高细节：>300Å，32倍降采样+超低端几何体
4. **按需渲染**：只在交互或LOD变化时渲染，闲置时帧率为0
5. **智能像素比**：
   - 交互时：像素比=1，最大化帧率
   - 静止时：恢复到1.5倍像素比，兼顾质量

### WebGL优化
1. **禁用抗锯齿**：默认关闭，大分子时
2. **关闭阴影**：>2万原子时自动禁用
3. **禁用模板/Alpha缓冲**：减少内存占用
4. **FASTEST着色器提示**：优化着色器性能
5. **Frustum Culling关闭**：分子级剔除对大分子无意义，直接关闭

### 后端优化
1. **流式PDB解析**：逐行解析，不加载整个文件到内存
2. **移除Biopython依赖**：纯字符串解析，内存占用降低80%
3. **化学键采样**：>5万原子时自动降采样计算键
4. **键数量限制**：最多15万条键，避免OOM
5. **简化二级结构**：基于Cα距离的快速算法
6. **自动GC**：解析后强制垃圾回收

## 功能特性

- **两种显示模式**：球棍模型（Ball-and-stick）和空间填充模型（Space-filling）
- **CPK着色法**：原子按元素类型着色
- **视角控制**：支持旋转、缩放、平移
- **二级结构识别**：自动识别α螺旋（红色）和β折叠（蓝色），用带状图表示
- **FPS实时显示**：右上角实时显示当前FPS和LOD级别
- **支持超大分子**：支持20万+原子（核糖体级别分子流畅交互

## 技术栈

**前端**：
- Three.js r160
- OrbitControls
- InstancedMesh + 顶点颜色
- LOD多级细节
- 按需渲染

**后端**：
- Python + Flask
- NumPy（向量化计算）
- 流式PDB解析
- 500MB大文件支持

## 安装与运行

### 1. 安装Python依赖

```bash
pip install flask flask-cors numpy
```

> 注意：不再需要biopython！已移除该依赖以减少内存占用

### 2. 启动后端服务

```bash
cd backend
python server.py
```

后端服务将在 `http://localhost:5000` 启动

### 3. 安装前端依赖

```bash
npm install
```

### 4. 启动前端开发服务器

```bash
npm run dev
```

前端将在 `http://localhost:3000` 启动

## 使用说明

1. 点击"选择PDB文件"按钮加载PDB格式的分子文件
2. 在"显示模式"中切换：
   - **球棍模型**：原子为球体，化学键为圆柱体
   - **空间填充**：原子按范德华半径显示，紧密堆叠
3. 勾选"显示主链带状图"查看蛋白质二级结构
   - 红色：α-螺旋
   - 蓝色：β-折叠
   - 灰色：无规卷曲
4. 使用鼠标控制视角：
   - 左键拖动：旋转分子
   - 滚轮：缩放视图
   - 右键拖动：平移视角
5. 调整"原子大小"滑块改变原子显示比例
6. "启用LOD优化"在查看大分子时自动降低细节级别以保证性能
7. 查看右上角实时FPS和LOD级别显示

## 常见问题

**Q: 加载大分子时浏览器卡顿怎么办？
A: 确保"启用LOD优化"已勾选，这会根据距离自动降采样。可尝试缩小视角，让LOD自动切换到更低级别。

**Q: 内存溢出怎么办？
A: 工具已限制最大20万原子，超过会自动截断。如果还是OOM可尝试：
1. 使用Chrome浏览器（内存管理最好）
2. 关闭其他标签页释放内存
3. 刷新页面重新加载

**Q: 如何获得最佳性能？
A: 
1. 使用Chrome浏览器
2. 启用硬件加速已开启
3. 使用独立显卡
4. 关闭"启用LOD优化"保持勾选
