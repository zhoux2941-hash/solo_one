## 1. 产品概述

地震波形模拟与分析工具是一款专业的地震数据可视化分析平台，面向地震学研究者、学生及相关领域从业者，提供直观的波形展示、波相标注、震中距估算等核心功能。

- 解决传统地震数据处理复杂、可视化不直观的问题
- 提供交互式学习和研究环境，降低地震数据分析门槛

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 使用所有分析功能、查看预置数据、上传波形数据 |

### 2.2 功能模块
1. **主分析页面**：波形显示区域、控制面板、分析结果展示
2. **数据管理模块**：预置地震事件选择、自定义数据上传
3. **波形处理模块**：滤波功能、缩放控制、波相标注
4. **结果计算模块**：震中距估算、震级推算

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主分析页面 | 波形显示区 | 三分量（南北、东西、垂直）波形同步显示，支持点击标注P/S波 |
| 主分析页面 | 数据选择面板 | 5个预置地震事件下拉选择，支持JSON格式波形数据上传 |
| 主分析页面 | 滤波控制面板 | 低通、高通、带通滤波选项，可调节截止频率 |
| 主分析页面 | 缩放控制区 | 时间轴放大/缩小按钮，支持鼠标滚轮缩放 |
| 主分析页面 | 分析结果区 | 实时显示P波时间、S波时间、P-S时差、震中距、推算震级 |

## 3. 核心流程

用户选择或上传地震数据 → 系统渲染三分量波形图 → 用户点击波形标注P波到达点 → 用户点击波形标注S波到达点 → 系统自动计算P-S时差 → 根据时差×8km/s估算震中距 → 根据波形振幅推算震级 → 用户可应用滤波器调整波形 → 用户可缩放时间轴查看细节

```mermaid

    A["选择/上传数据"] --> B["渲染三分量波形"]
    B --> C["标注P波到达时间"]
    C --> D["标注S波到达时间"]
    D --> E["计算震中距(时差×8km/s)"]
    E --> F["推算地震震级"]
    F --> G["可选:应用滤波"]
    F --> H["可选:缩放波形"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝色系（#1e3a5f）代表专业科技感
- **辅助色**：青色（#0ea5e9）用于交互元素、橙色（#f97316）用于P波标注、红色（#ef4444）用于S波标注
- **背景**：深色主题（#0f172a）搭配微妙网格纹理，营造科研氛围
- **按钮风格**：圆角设计，悬停时有微妙发光效果
- **字体**：JetBrains Mono（等宽字体，适合数据展示）搭配 Inter
- **布局**：三栏式布局，左侧控制面板、中间波形显示区、右侧结果面板
- **视觉风格**：科技感、专业、数据可视化导向

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主分析页面 | 波形显示区 | Canvas绘制的波形曲线、网格背景、时间/振幅坐标轴、P/S波垂直线标记 |
| 主分析页面 | 控制面板 | 下拉选择器、频率输入框、滤波类型切换、缩放控制按钮组 |
| 主分析页面 | 结果面板 | 数据卡片布局、大号数字展示、单位标注、实时更新动画 |

### 4.3 响应式
- 桌面端优先，三栏布局
- 平板端：左右面板可折叠
- 移动端：单列布局，面板堆叠显示
- 触摸优化：增大点击区域，支持双指缩放

### 4.4 交互细节
- 波形悬停显示十字准线和时间/振幅值
- 标注点支持拖拽调整
- 滤波切换时有平滑过渡动画
- 数据加载时显示骨架屏
