# NFC门禁卡模拟与审计系统

基于Electron + Node.js开发的NFC门禁卡模拟与审计系统，支持ACR122U等PC/SC读卡器。

## 功能特性

### 🔍 实时监控
- 自动检测靠近的NFC卡片
- 实时显示卡片基本信息（UID、SAK、ATQA）
- 判断卡片是否可模拟（数据库匹配）
- 系统通知提示"此卡可模拟"

### 💳 卡片分析
- 读取Mifare Classic卡全部16个扇区数据
- 自动检测加密扇区
- 使用默认密钥尝试认证（A类: FFFFFFFFFFFF, B类: 000000000000）
- 扇区数据可视化展示
- 导出JSON格式的dump文件

### 🔓 密钥破解
- 嵌套认证攻击（Nested Authentication Attack）
- 暴力破解模式
- 破解进度实时显示
- 破解成功的密钥自动存入数据库

### 📱 卡片模拟
- 读卡器切换到Target模式（卡片模拟模式）
- 模拟已存储的门禁卡
- 支持同时管理多张模拟卡
- 一键切换当前模拟的卡片
- 记录每次模拟的时间和位置

### 📊 审计报表
- 统计卡片使用频率
- 按时间段查询使用记录
- 使用频率热力图（星期×小时）
- 24小时时间分布折线图
- 地点分布饼图
- 导出PDF格式审计报告

### 📝 操作日志
- 记录所有操作（卡片检测、分析、模拟、破解等）
- 支持按操作类型筛选
- 记录操作人、时间、详情

## 硬件要求

- ACR122U NFC读卡器（或其他兼容PC/SC的读卡器）
- Mifare Classic 1K/4K NFC卡

## 安装步骤

### 1. 安装驱动
- **Windows**: 安装ACR122U驱动程序
- **Linux**: 安装 `pcscd` 和 `libpcsclite-dev`
- **macOS**: 系统自带PC/SC支持

### 2. 安装Node.js依赖
```bash
npm install
```

### 3. 重新构建原生模块
```bash
npm run rebuild
```

### 4. 运行应用
```bash
npm start
```

### 5. 开发模式
```bash
npm run dev
```

### 6. 打包应用
```bash
npm run build
```

## 数据库结构

### cards 表
- 存储卡片基本信息（UID、SAK、ATQA、名称等）

### sectors 表
- 存储每个扇区的数据、密钥、访问条件
- 标记是否加密、是否已破解

### keys 表
- 存储所有破解/导入的密钥
- 记录密钥来源（默认/破解/导入）

### audit_records 表
- 存储审计记录（模拟时间、读头ID、位置）

### operation_logs 表
- 存储所有操作日志

## 使用说明

### 1. 读取真实卡片
1. 连接ACR122U读卡器
2. 将卡片放在读卡器上
3. 在"卡片分析"页面点击"开始分析"
4. 系统自动读取所有扇区并尝试破解密钥

### 2. 模拟卡片
1. 在"卡片模拟"页面选择要模拟的卡片
2. 输入模拟位置（可选）
3. 点击"开始模拟"
4. 读卡器切换到Target模式，开始模拟卡片

### 3. 切换模拟卡
1. 直接点击其他卡片的"开始模拟"按钮
2. 系统自动停止当前模拟并切换到新卡片

### 4. 生成审计报表
1. 在"审计报表"页面选择卡片和时间范围
2. 点击"查询统计"查看图表
3. 点击"生成PDF报告"导出完整报告

## 常见问题

### Q: 读卡器未检测到
A: 检查驱动是否正确安装，读卡器是否连接正常。Windows系统需要安装ACR122U驱动。

### Q: 无法读取卡片
A: 确保卡片是Mifare Classic类型，卡片位置正确，电量充足。

### Q: 密钥破解失败
A: 部分卡片使用强密钥，嵌套攻击可能需要较长时间。可以尝试暴力破解模式。

### Q: 模拟失败
A: 确保读卡器支持Target模式（ACR122U支持），卡片数据完整。
