# POS小票打印机 - WebUSB

基于WebUSB的热敏小票打印机收据打印工具，支持爱普生TM系列、佳博等主流POS打印机。

## 功能特性

- 🖨️ **WebUSB连接** - 浏览器直接连接USB打印机，无需驱动
- 📋 **多种模板** - 支持购物小票、退款单、测试单三种模板
- 🛒 **商品管理** - 实时添加/删除商品，自动计算小计
- 👁️ **实时预览** - 所见即所得的收据样式预览
- 📄 **连续打印** - 支持一次打印多张收据
- 🔍 **状态监测** - 实时监测缺纸/过热/开盖状态
- ⚡ **快速打印** - 优化打印速度，每张<3秒
- 💳 **支付二维码** - 内置二维码生成功能

## 支持的打印机

- 爱普生 EPSON TM 系列 (T88, T20, U220等)
- 佳博 Gprinter 系列
- 其他支持ESC/POS指令的热敏打印机

## 浏览器要求

- Chrome 61+
- Edge 79+
- 需要HTTPS或localhost环境

## 使用方法

### 1. 启动本地服务器

```bash
node server.js
```

### 2. 访问应用

在浏览器中打开: `http://localhost:8080`

### 3. 连接打印机

1. 点击"连接打印机"按钮
2. 在弹出的设备选择框中选择您的热敏打印机
3. 点击"连接"

### 4. 编辑收据内容

- 修改店铺信息（名称、地址、电话）
- 添加/删除商品列表
- 选择支付方式
- 设置支付二维码内容

### 5. 打印

- 选择打印模板
- 设置打印份数
- 点击"打印收据"或"测试打印"

## 核心技术

- **WebUSB API** - 浏览器USB设备通信
- **ESC/POS指令集** - 热敏打印机标准控制指令
- **QRCode.js** - 二维码生成
- **GB18030编码** - 中文支持

## 打印速度优化

- 使用批量USB传输减少通信开销
- 优化指令序列，减少冗余命令
- 预编码文本数据
- 异步并行处理

## 注意事项

1. WebUSB需要在安全上下文(HTTPS或localhost)中运行
2. 首次连接需要用户授权
3. 不同打印机的ESC/POS指令支持可能有差异
4. 建议使用58mm或80mm热敏纸

## 故障排除

### 无法连接打印机
- 检查打印机是否开机并连接USB
- 检查浏览器是否支持WebUSB
- 尝试更换USB端口

### 打印乱码
- 确认打印机支持GB18030编码
- 检查打印指令格式是否正确

### 二维码不显示
- 确认打印机支持QR码打印指令
- 二维码内容不要过长
